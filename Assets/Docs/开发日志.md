## 阶段十三：天气 · 电力 · 水源（10-27）

- **天气与气温（ClimateSystem）**：小 / 中 / 暴雨、微 / 中 / 大风、小 / 中 / 大雪、冰雹随机出现，每种持续 1～3 回合；气温随机漂移，异常度越高越容易极端。炎热时体力消耗加快，寒冷时走路变慢、没防寒装备会掉血，冰雹会砸伤营地外的人；**暴雨 + 大风 = 亚空间风暴**。顶部天数下面显示天气和气温 `e7453fc`
- **电力系统（PowerGrid）**：风力发电机按风力发电并存电；建造模式里选「电线」点两个节点连成电网；营地加温器 / 降温器、水源净化器要接电才工作；AI 终端机自带一台小型风力发电机 `e7453fc`
- **水源（WaterWorks）**：下雨不再直接给水——雨水收集器接雨，水源净化器通电后把雨水净化成净化水放进仓库 `e7453fc`
- 新建筑（风力发电机、加温器、降温器、雨水收集器、净化器）由代码生成像素图，以后有美术素材可以用同名资产替换；**终端机面板新增「能源」页**，调设备档位、看电网和水量 `e7453fc`
- **删除临时调试工具**：SAN 调节面板、事件测试按钮、迷雾测试组件、空间扭曲测试按钮（场景物体 + 脚本 + 翻译条目） `e7453fc`
- **电力系统重做**：发电机只发电，电存进电池（终端机自带小电池，可另建**蓄电池**，需要终端机 Lv1）；电池会自放电、充电有损耗；电不够时按优先级拉闸——加温器 / 降温器先供电，净化器后供电，不再全网一起停 `4afe1ea`
- **每日饮水配给**：每人每天喝 0.5 份净化水（炎热时多喝），最缺水的人先喝；没喝上的人记缺水天数；收集器满了、净化器没电、水快喝完时各提示一次 `4afe1ea`
- **顶部资源栏**：天数左边显示电力（储电 / 发电 / 用电 / 断电），右边显示净化水（库存、还够几天、收集器里的雨水）和「终端机」快捷按钮 `4afe1ea`
- **悬停信息框**：鼠标停在 NPC 上显示姓名、职业、在做什么和状态；停在建筑上显示是否在工作 `4afe1ea`
