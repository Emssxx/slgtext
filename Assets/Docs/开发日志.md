## 阶段二十四：新枪 ABA-AR15 · 镭射瞄准线（11-13）

- **新枪 ABA-AR15**（图在 `Resources/WeaponArt/aba-ar15`：枪身、弹匣、上弹器、内构造、拉栓、伸缩枪托、枪火、子弹）：手感轻快稳定——700 发/分，每枪上跳范围窄、往后顶得轻、回正快（战斗步枪 = 慢、跳得忽大忽小；X95 = 直往后顶得狠）；上弹器往后走时从枪身窗口露出内构造；伸缩枪托取出时左手往后拉开。ABA 队员的 Rifle Model 可以选 aba-ar15（30 发、伤害 14、散布 1.15、换弹更快） `2cfb944`
- **镭射瞄准线**（枪的属性，WeaponDef 新增"镭射"一栏：颜色、粗细、长度、发射点光团大小）：拿着有镭射的枪就开着，从镭射十字沿枪管方向射出一条细激光、越远越淡，发射点有一小团光，不受光照（黑暗里也看得见）；取出动画播完才开、死了关掉。目前只有 AR15 有 `2cfb944`
- npc1 在测试窗口直接选步枪时，先把枪挂到背带上再播取出动画 `2cfb944`
- **战斗数值搬进枪的数据**（WeaponDef 新增"战斗数值"一栏）：弹匣、伤害、散布、射速、射程、要害、击退、换弹时间都成了枪的属性，谁拿都一样，人的等级 / 紧张 / 体力再乘上去。AbaForce 里各把枪的数值删掉了，只剩"拿哪把步枪 / 手枪"；数值每秒按枪的数据刷新一次，运行中改武器数值文件马上生效。战斗步枪动画射速统一成 750（原来动画 400、游戏 750），AR15 改为原型 M4A1：800 发/分、射程 11 `02a9f96`
- **瞄准配件影响命中**：可变倍率瞄准镜（AR15：1~3 倍，近处 1 倍、越远倍率越高、散布越小，高倍边走边打难一点）和镭射指示（边走边打散布 ×0.85）；子弹击退也改成读枪的属性（手枪有、步枪没有，防护服手枪 2.5） `02a9f96`
- **激光照亮经过的地方**：沿着激光放 5 团小点光，越远越暗（参数 laserLight / laserLightRadius，AR15 = 0.35） `02a9f96`
- **新枪 AKM + AK 式换弹**（图在 `Resources/WeaponArt/akm`；CharacterRigBase.AK.cs，持枪手类型新增"AK式"）：AK 的弹匣是"摇进去"的——弹匣前端先挂上枪的弹匣挂载旋转点（WeaponDef 新参数 magRock），再绕这个点往后一转卡到底，取下时反过来往前转。三种换弹都由左手拉栓 `1620f27`
  - 快速：左手拉住拉栓、枪口上抬 30°，右手拿新弹匣把旧弹匣敲下来（旧弹匣转着飞出去），新弹匣摇进去，左手松开拉栓弹回
  - 战术：枪抬起 80°，右手拿着新弹匣把旧弹匣摇下来（两个都在右手），摇进新的，枪口降到 30° 左手上膛，旧弹匣放回配件
  - 普通：先摇下旧弹匣放回去，再拿新弹匣摇进去、上膛
- **普通 NPC 的武器数值也读枪的数据**：防护服手枪、斧头、锤子都有了自己的 WeaponDef（斧头 / 锤子是"近战"种类，只有伤害、距离、间隔、胆量），数值照搬原来的（手枪 3 级时散布 10°、伤害 9）；防护服手枪的弹匣容量也从这里读。散布、后坐、子弹速度、击退全看手上那把枪 `1620f27`
- **伤害 = 武器基础伤害 + 武器操作等级修正**（Ballistics 新参数 levelDamageAdd：1~5 级 = −2 / −1 / 0 / +1 / +2），再看武器的要害几率；拳头不修正 `1620f27`
- **ABA 扔手雷**（纯规则，不走 LLM）：`ae2caa8`
  - 扔的动作（NpcRigB.Throw.cs）：npc2 腰上挂两颗，扔一颗少一颗。辅助手离开枪去腰上拿 → 胸前拔环 → 往后上方抡到头后 → 从头顶猛地甩出去 → 回到枪上，身体跟着后仰、前压
  - 飞和炸（Grenade.cs）：带弧线边飞边转，落地滚一小段，引信 1.5 秒；爆炸图 + 一闪橙光，半径里、没有墙挡着的都扣血（越近越多）并往外推。手雷不认人，自己人也会炸到
  - 什么时候扔（AbaOperative + AbaForce「手雷」一栏）：距离 2.5~6.5、目标躲在掩体后打不到 / 身边扎堆 / 是大家伙才扔；落点附近有自己人不扔，同一人冷却 8 秒、全组两颗之间隔 2.5 秒；扔的时候喊"手雷！"。新物品 grenade
- **两把新手枪**：ABA-P225（原型 SIG P225）、ABA-17（原型格洛克，带连发，ABA 拿它会像步枪一样打一串）；AbaForce 新参数 Pistol Model 选队员的手枪，胸挂上 / 手上的手枪跟着换 `ae2caa8`
- **拉栓狙击枪 ABA-M2**（原型 M24 一类栓动狙）：每开一枪手动拉一次栓——左手离开握把抓拉机柄，往上抬、往后拉到底、推回去、压下锁住，每一下枪都轻轻抖（CharacterRigBase.Bolt.cs，所有角色共用）；换弹也是单独一套"拉栓式"，三种换弹最后都要拉栓（CharacterRigBase.BoltReload.cs）；ABA 拿它一枪一枪打，拉栓时不开枪 `ae2caa8`
- **怪物外观：被感染的研究员**（InfectedRig，图在 `Resources/EnemyArt/infected`）：防护服坏了没有灯，面罩里一只大眼球，瞳孔会乱转、锁定目标后一直盯着；两只镰刀一样的变异手轮流砍；待机时身体慢慢转、不规则地痉挛，走路慢、拖着走。走路 / 受击 / 倒地用通用骨架。目前只有外观和测试开关，还没接进敌人系统 `ae2caa8`
- **怪物接进敌人系统**：被感染的研究员（InfectedRig）第 4 天起 2~4 只一群来袭；死后一半几率钻出 2~3 只眼球蜘蛛幼体 `f82004a`
- **眼球蜘蛛**（SpiderRig，图在 `Resources/EnemyArt/spider`）：幼体 0.5 倍（快、脆，活 60 秒长成青年体）→ 青年体 1.2 倍（再活 120 秒 30% 几率变异）→ 变异体 3 倍（又慢又硬，会拆墙）；EnemyDefs 新增 hatchInto / growInto 等参数 `f82004a`

- **扔手雷所有角色通用**（CharacterRigBase.Throw.cs）：npc1 也能扔挂环上的手雷（胆量 ≥ 25 才敢扔，营地里不一起扔）；拿步枪扔时不开枪，拿手枪可以边打边扔。CombatTest 可以指定 NPC 拿哪把枪 `f82004a`

## 阶段二十五：新地图规则 · 永久雾 · 区域（11-14 ～ 11-16）

- **永久雾**（FogManager 新开关 Permanent Fog，默认开）：营地是固定基地，营地外永远是雾，NPC 视野 / 光照 / 终端机都揭不开；只剩"雾 / 没雾"两种状态。没雾的地方 = 营地地砖范围往外 1 格 + 用 ClearRegion 登记的区域（以后 AI 导演生成区域时用，区域消失调 CoverRegion 盖回去）。关掉开关回到原来的三态战争迷雾 `e4e5f1e`
- **人在雾里掉理智**（NpcHealth 新参数 fogSanityPerSecond，默认每秒 1）：营地和雾散开的区域里不掉 `e4e5f1e`
- **地图只生成营地**（TerrainGenerator.GenerateCampOnly）：营地外全是空地，不再按种子生成湖 / 沼泽 / 树 / 石头 / 矿，资源以后只来自区域；种子只影响营地地砖的缺角 / 破损，不再在事件栏报种子。TerrainSystem 新开关 legacyTerrainGeneration 可切回旧地形 `e4e5f1e`
- 变异眼球蜘蛛血量 600 → 12000 `e4e5f1e`
- **区域导演**（新脚本 RegionDirector）：营地外的"地图"靠区域一块块出现——紧贴营地的一块长方形雾散开，里面按种类放资源 / 敌人，过几天雾合上、区域连同没采完的资源和活着的敌人一起消失。四种：废弃营地（资源多、没敌人）/ 怪物巢穴 / 其他人类营地 / ABA 临时指挥部；安全期内只出废弃营地。AI 导演只从清单里选 region_xxx，放哪放什么由代码决定；另有每天掷骰 + 连续几天没区域必出的保底。测试键 F9 生成、Shift+F9 让现有区域消失 `d95d7f6`
- TerrainSystem.AddResource：运行时往地图上加资源（区域用），放不下就不加 `d95d7f6`
- 营地没雾的范围把 NPC 闲逛圈也算进去，每秒核对一次（地形生成好 / 终端机挪位置都能跟上），NPC 平时闲逛不会再踩进雾里掉理智 `d95d7f6`
- **营地美术**（Resources/CampArt，找不到图自动退回原样）：手绘格栅地砖；墙换成铁丝网（南北正面网、东西侧面柱）；营地出入口的升降杆大门（CampGate：NPC 走近自动抬杆、红绿灯，门关着时敌人和 ABA 走不过去、NPC 照常进出）；开局在围墙内角落摆一个 ABA 旧集装箱（CampProps） `d95d7f6`
