## 阶段十三：天气 · 电力 · 水源（10-27）

- **天气与气温（ClimateSystem）**：小 / 中 / 暴雨、微 / 中 / 大风、小 / 中 / 大雪、冰雹随机出现，每种持续 1～3 回合；气温随机漂移，异常度越高越容易极端。炎热时体力消耗加快，寒冷时走路变慢、没防寒装备会掉血，冰雹会砸伤营地外的人；**暴雨 + 大风 = 亚空间风暴**。顶部天数下面显示天气和气温 `e7453fc`
- **电力系统（PowerGrid）**：风力发电机按风力发电并存电；建造模式里选「电线」点两个节点连成电网；营地加温器 / 降温器、水源净化器要接电才工作；AI 终端机自带一台小型风力发电机 `e7453fc`
- **水源（WaterWorks）**：下雨不再直接给水——雨水收集器接雨，水源净化器通电后把雨水净化成净化水放进仓库 `e7453fc`
- 新建筑（风力发电机、加温器、降温器、雨水收集器、净化器）由代码生成像素图，以后有美术素材可以用同名资产替换；**终端机面板新增「能源」页**，调设备档位、看电网和水量 `e7453fc`
- **删除临时调试工具**：SAN 调节面板、事件测试按钮、迷雾测试组件、空间扭曲测试按钮（场景物体 + 脚本 + 翻译条目） `e7453fc`
- **电力系统重做**：发电机只发电，电存进电池（终端机自带小电池，可另建**蓄电池**，需要终端机 Lv1）；电池会自放电、充电有损耗；电不够时按优先级拉闸——加温器 / 降温器先供电，净化器后供电，不再全网一起停 `4afe1ea`

## 阶段十七：NPC 社会系统（11-06）

- **AI 请求调度器**（AiScheduler）：所有 AI 请求先排队，由代码决定谁先用——主模型 / 小模型两条队列互不等待；按优先级先后，排久了优先级慢慢升高；过期或已经没用的请求直接作废（调用方用代码兜底）；每种请求每天有次数上限；按 **F9** 看各类请求占了多少算力 `4db8096`
- **小模型通道**（默认 qwen3:4b）：和主模型同时加载、同时跑，专做短活（输入分类、短台词、闲聊语气判断）；没装 / 太忙 / 超时一律回到代码兜底 `4db8096`
- **安全感**（NpcSecurity，纯代码）：看营地四周被围墙 / 建筑 / 地形挡住了多少、有没有被整个围起来、身边有没有同伴、异常度和危险；每个人底线不同（越胆小底线越高），低于底线就会自己想办法 `4db8096`
- **NPC 自主意图**（NpcIntents）：安全感不足时，AI 只能从代码给的清单里选一件事（建造 / 采集 / 找吃的 / 回营地 / 休息 / 不做），代码审核后拆成任务链——自动放蓝图（优先补围墙缺口）→ 取材料 → 材料不够先去采集 → 施工；头顶气泡说出想法，日志记下打算。玩家指令、饿 / 累 / 逃命都优先于他自己的计划 `4db8096`
- **请人帮忙**：决定建造时可以点名请最多 2 人帮忙；答不答应**由代码算**（尊重、好感、信任、利他心、疲劳），小模型只写回答的那句话；被无理由拒绝会降低好感 / 信任 `4db8096`
- **选领导与早会分工**（NpcSociety）：人数够了就开会，**代码投票**选领导（尊重为主）；大家对领导不满会重选。领导每天早上用 AI 给每个人分组（修建 / 采集 / 找吃的 / 照顾伤员 / 休整），听不听由尊重值决定；分工只管闲下来干什么 `4db8096`
- **关系系统扩充**：新增**尊重值**；每次关系变化记一句原因给 AI 读；由数值推出"感觉"标签（仇恨 / 厌恶 / 亲近 / 敬重……），变了写日志。一起建成建筑会互相加好感和尊重 `4db8096`
- **闲聊语气判断**：AI 现场写的闲聊，聊完让小模型读实际说的话判断语气，再由代码按语气结算好感 / 信任（本地剧本台词仍按话题结算） `4db8096`
- **营地范围**（CampZone，玩家看不见）：以营地中心为中心的长方形，一圈边切成一段段"墙位"，每段的状态是已挡住 / 有蓝图 / 空着 / 放不下 / 出入口；留出入口不修墙（还没有门）。安全感的围合度、修墙位置、AI 提示词里的"围墙还差几段"都改用它 `8b2bb11`
- **按分工干活**（代码执行，不调 AI）：有分工的人按各自"活的优先顺序"找活——建造 / 搬运（把石头运到空墙位放好蓝图，或打水倒进雨水收集器）/ 采集 / 医疗 / 探寻 / 休息；只有没分工的人才会因为安全感不足自己琢磨 `8b2bb11`
- **领导出现方式改版**：前几天大家不熟不会有领导；要等契机（一半以上的人不安 / 危险靠近 / 有人请人帮忙），最晚第 6 天也会出现。由**小模型当观察者**读每个人的性格数值判断谁最合适并给理由，失败时用代码按同样数值打分；领导必须以身作则干活，AI 漏分或分工失败由代码补齐 `8b2bb11`
- **NPC 任务栏**（NpcTaskPanel，右下角，替换原来的 AI 调试文字）：按分组显示每个人此刻在做什么，领导名字黄色、安全感不足的人带红色「!」，点名字打开对话 `8b2bb11`
