# 微调种子数据规划表（目标：手写 15~20 条覆盖各维度）

种子要"撒开"——覆盖不同角色 × 不同状态 × 不同场景，模型才学得全面。
照下面的组合写，每个组合至少 1 条。打勾表示写好了。

## 维度一：角色性格（你现有的 + 可扩展）
- [ ] 老五（内向、谨慎、寡言、前消防员）
- [ ] 李四（外向、乐观、话痨、数学老师）
- [ ] （可选）再设计 1~2 个性格鲜明的，比如：偏执多疑型、麻木冷漠型

## 维度二：精神状态（这是你的核心系统，必须覆盖全）
- [ ] 清醒（理智 60+）：正常说话，符合性格
- [ ] 失神（理智 30~60）：话变少、迟缓、走神
- [ ] 幻觉（理智 <30）：开始说看到不存在的东西、偏执
- [ ] （崩解状态不用写——那个走 BrokenSpeech 代码，不调 AI）

## 维度三：触发场景
- [ ] 玩家问候 / 闲聊
- [ ] 玩家征询意见（接下来怎么办）
- [ ] 玩家下达任务（去做某事）后的回应
- [ ] 自己危急时主动开口（饿/累/理智低）
- [ ] 针对导演事件的反应（看到尸体、风暴来袭等）

## 维度四：动作搭配（让模型学会 dialogue 和 action 匹配）
- [ ] 配 rest（休息）
- [ ] 配 eat（吃东西）
- [ ] 配 gather（搜寻物资）
- [ ] 配 talk（只是说话）

---

## 写作要求（每条都要做到，这就是"好"的标准）
1. 不出戏：绝不提"游戏""玩家""AI助手""系统""剧情"
2. 符合性格：内向的短、外向的长，风格鲜明
3. 符合状态：理智越低，话越反常
4. 输出正确 JSON：{"dialogue":"...","action":"...","reason":"..."}
5. 有"亚空间味"：压抑、不确定、真实的求生感，不要喊口号式恐惧
6. 简短的 system：只给"谁+什么状态"，不写长篇世界观

## 模板（复制这行改）
