# 亚空间生存 SLG

> 一个由 AI 驱动的「活体世界」生存沙盒。
> 玩家扮演一台**只能用语言交流的生存支援 AI**，引导一群被卷入亚空间、拥有各自人格的幸存者活下去。

**项目本质：探究 LLM（大语言模型）在游戏里「该用在哪、不该用在哪」。**

- 引擎：Unity 6（6000.4）· C#（约 115 个脚本、2.5 万行）
- AI：本地 Ollama（qwen2.5 / qwen3，8GB 显存可跑）· 可切换云端 Claude / OpenAI / Gemini
- 语言：中文 / 日本語（界面、提示词、NPC 台词全部跟随主菜单语言）
- 开发期间：2026-06 ～（持续开发中）· 个人项目

> **日本語の概要**
> 言葉でしか生存者とやり取りできない「生存支援AI」となり、亜空間に迷い込んだ人々を導くサバイバル SLG です。
> LLM は「NPC の会話」「AI ディレクターによるイベント生成」「プレイヤーの自然言語指示の解析」の 3 つだけに使い、
> 行動決定・移動・数値計算などはすべてルールベースのコードで処理しています。

## 设计核心：LLM 只做三件事

在游戏里接入 LLM 最容易出现的问题是：慢、不稳定、会「编」。所以本项目先定下一条边界——

| LLM 负责（白名单） | 规则代码负责（LLM 绝不碰） |
|---|---|
| NPC 对话生成 | NPC 行为决策、移动、寻路 |
| AI 导演事件生成 | 信任度与是否听从指令 |
| 玩家自然语言指令的理解 | 关系数值、精神状态、世界规则结算 |
| | 任何每帧 / 高频 / 玩家等着看结果的逻辑 |

加任何新功能前，先过三道判断：

1. 它需要**创造**还是**判断**？创造 → 可以用 LLM；判断 → 规则。
2. 它是**低频、玩家可以等待**的吗？不是 → 规则。
3. 出错时是「表现差」还是「逻辑崩」？逻辑崩 → 必须规则。

完整架构见 [`Assets/Docs/游戏架构总纲.md`](Assets/Docs/游戏架构总纲.md)。

## 让 LLM 稳定工作的几个做法

- **演员提示词（Actor Profile）**：每个 NPC 一份 LLM 扮演时最先读的设定。年龄、职业、家庭、对 AI 的初始信任等**事实由代码生成**，LLM 只补写「说话方式、对事件的态度」等演绎部分；LLM 没写好时用代码模板兜底，游戏任何时候都有一份完整的设定。
- **事件编年史**：导演事件、崩溃、死亡都会记下来，连同每个 NPC 自己的经历和看法。聊天时按话题挑出相关的几条，NPC 能用自己的视角谈论发生过的事，而不是凭空编造。
- **指令由代码解析，LLM 只负责「说」**：玩家说「王芳，去 30,12 砍树」，由词库 + NPC 名册 + 动词表识别出谁、做什么、去哪里；LLM 只为这个 NPC 生成一句符合人设的回应。
- **后台任务队列**：非紧急的 LLM 任务（写演员设定、写事件看法、闲聊配音）排队执行，玩家一开口就让路；失败、超时、没开模型时都有本地台词兜底。
- **语言守卫**：检查 LLM 回复的语言是否正确，不对就重试 → 翻译修复 → 安全占位台词。整段提示词也按界面语言书写，避免中日混杂。
- **小模型友好**：用当前语言的简短世界概况代替整份世界数据，防止上下文溢出；兼容 qwen3 等思考型模型（自动关闭思考、过滤 `<think>`）。

## 游戏系统（全部为规则代码）

- **NPC 自主行为**：饿了去吃、累了休息、物资不足外出搜寻、危险时逃跑；没事时发呆、闲逛、找同伴闲聊。性格数值影响行为阈值（勇敢的人更晚逃跑）。
- **健康系统**：饥饿值、水分、体力每秒结算；受伤、生病、口渴、疲惫、精神病等状态词条影响移动、工作和人际关系。
- **精神状态**：理智值决定清醒 / 恍惚 / 幻觉 / 崩解，崩解后身体异变。
- **AI 终端机**：玩家的「身体」。合成、科技树、等级升级、建造解锁。
- **建造**：规划区蓝图 → 指派 NPC 施工；多格建筑、占地预览；墙会挡路，建成后重新烘焙寻路。
- **天气与气温**：雨、风、雪、冰雹，暴雨加大风触发「亚空间风暴」；炎热、寒冷影响体力与生命。
- **电力与水源**：风力发电、电池储电、电线连网、按优先级断电；雨水收集 → 净化器净化 → 每日饮水。
- **地图种子与地形**：同一个种子生成同一张地图；土地、营地地砖、沼泽、湖泊，以及树、石头、矿石等可采集资源。
- **战争迷雾**：未探索 / 探索过 / 视野内三态，终端机激活后大范围揭雾。
- **界面**：每个 NPC 一个专属对话窗口和聊天档案；电子表风格的 HUD；NPC 锁定框随生命值变色，死亡时有专门的演出。

## 运行方法

1. 用 **Unity 6000.4.11f1** 打开项目，从 `Assets/Scenes/MainMenu.unity` 开始运行。
2. **本地模型（推荐）**：安装 [Ollama](https://ollama.com/)，执行 `ollama pull qwen2.5:7b`，保持 Ollama 运行。
3. **云端模型（可选）**：在主菜单选择 Claude / OpenAI / Gemini，把自己的 API key 放到 `Application.persistentDataPath` 下（Claude：`apikey.txt`，OpenAI：`openai_key.txt`，Gemini：`gemini_key.txt`）。key 文件在工程外面，不会进 Git。
4. 不开任何模型也能玩：对话和事件会使用本地台词兜底。

常用操作：`B` 建造模式 · `Y` 打开对话 · `I` 仓库 · 滚轮缩放 · 中键 / WASD 移动镜头 · `H` 回营地
