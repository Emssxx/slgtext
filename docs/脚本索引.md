## 3. 脚本按系统分组

### 🤖 AI 接入层（LLM 调用出口）
- **AiScheduler** — AI 请求调度器，所有 AI 功能必须走它排队（地基）
- **AIClientHub** — LLM 调用统一出口 + 选哪家模型
- IAIClient / IAIBackgroundClient — 客户端接口
- OllamaAIClient（本地，主力）、ClaudeAIClient、OpenAIClient、GeminiAIClient — 各家客户端
- LlmJobQueue — 后台 LLM 任务队列
- PromptContext — 把世界状态整理成提示词上下文
- LanguageGuard — 检查 AI 回复语言（最后一道保险）
- DialogueCleaner — 显示前清洗 NPC 对话
- AIModelDebugUI、AIStatusIndicator — AI 状态显示

### 🎬 AI 导演 & 事件
- **AIDirector** — 游戏的"讲述者"，推进回合、施加生存压力
- EventExecutor — 执行导演给出的事件
- EventChronicle — 事件里某个 NPC 的第一视角记录
- OpeningDirector — 开场（第一天）演出
- RegionDirector — 雾里的区域（废弃营地 / 巢穴 / ABA 指挥部），测试键 F11
- ScreenEffectManager — 屏幕闪色 / 震动等效果

### 🧠 NPC 决策与社会（规则为主，14B 只做低频选择）
- **NpcIntents** — NPC 自主意图（AI 判断，代码执行）
- **NpcSociety** — 领导与分组、早会分工
- **CampAdvisor** — 营地参谋（隐形 4B 小模型），规则手册在 `Resources/AI/advisor_rules.txt`
- NpcSecurity — 安全感（自发行动的动机）
- NpcDecisionRules + NpcBehaviorDriver — 行为决策状态机及驱动
- TrustRules — 信任度 → 听不听指令
- RelationshipManager — NPC 之间关系读写
- NpcBusy — "谁正在被哪个系统指挥"的占用登记
- NpcRoster — NPC 名册

### 💬 NPC 对话 & 表达（LLM 白名单）
- **NpcAgent** — 玩家与单个 NPC 的一对一对话
- NpcActorProfile + NpcActors — NPC 演员提示词及管理
- NpcMemory — 聊天记录 / 记忆档案
- NpcChat — 对话统一出口
- IdleChat、IdleChatLines、LlmIdleChatVoice — NPC 闲聊（本地台词 + LLM 配音）
- BrokenSpeech — 人格崩解后的疯话（不调 AI）
- NpcSpeechBubble — 头顶对话气泡

### 🗣️ 玩家指令
- **CommandParser** — 自然语言 → 动作 + 目标
- NpcCommands — 指令种类
- TaskPlanner — 复杂指令拆成任务
- NpcTask + NpcTaskRunner — 任务及任务队列执行器

### 🚶 NPC 行动执行（纯规则）
- NpcMover — NavMesh 寻路移动
- NpcNav — 寻路小工具（营地中心、导航网格采样）
- NpcNeedRunner — 需求行为执行（吃 / 喝 / 休息）
- NpcIdleBrain + NpcIdleManager + IdleActivities — 闲置行为
- NpcInventory — NPC 物品栏
- NpcHealth — 健康系统 / 状态词条
- NpcDeathManager — 死亡与全灭判定
- MentalState — 精神状态等级

### 🧬 NPC 生成与数据
- **GameData** — 所有纯数据类（NpcData / WorldState 等）
- **WorldManager** — 世界状态的唯一真相来源，开局生成 NPC
- NpcGenerator + TraitPool — 词条池随机生成 NPC
- NpcSpawner — 按数据在场景里生成 NPC
- NpcView — 数据 id ↔ 场景物体

### 🌍 世界规则（纯规则，AI 只读）
- **WorldRules** — 亚空间对人的影响（理智 / 健康 / 崩解）
- WorldLore — 世界观文本
- GameLexicon — AI 词库
- ClimateSystem — 天气与气温
- PowerGrid + PowerBuildings — 电力
- WaterWorks — 水源
- ProgressionRules — 营地进度（终端机等级等）
- CampGoals — 营地目标

### 🗺️ 地图 · 地形 · 迷雾
- MapSeed — 地图种子
- TerrainGenerator + TerrainSystem + TerrainArt — 地形生成
- ResourceNode — 天然资源（草 / 树 / 石 / 矿）
- GridManager、GridOverlay、GridClickInput（旧，默认关） — 网格
- CampZone — 营地范围（只给代码用）
- FogManager、FogRenderer、FogOfWarRenderer、FogParticleRenderer、FogVisionUpdater、FogTerminalGate — 迷雾（现在营地外是永久雾）

### 🏗️ 建造
- **BlueprintDesigner** — 蓝图规划（B 键，取代旧建造模式，2570 行，最大的脚本）
- Blueprint、BlueprintInbox — 蓝图数据、NPC 交计划提示
- Construction — 规划区建造与施工指派
- BuildManager、BuildButton、BuildModeToggle、BuildableData — 旧建造流程 / 建造物定义
- StructureHealth — 墙的耐久

### 💻 AI 终端机
- TerminalPanelUI（老电脑画面）、TerminalConsole（命令台）
- TerminalController、TerminalClickHandler、TerminalVisual
- TerminalData、TerminalDatabase、TerminalWorkshop — 合成表 / 科技树 / 工作台

### 📦 物品
- ItemData、ItemDatabase、ItemUseRules
- StoragePanelUI — 营地仓库面板
- WorldItemMarker、LocationMarker — 场景里的物品 / 地点标记

### ⚔️ 战斗 · 敌人 · ABA 清除小组
- **Ballistics** — 真实弹道
- WeaponDef — 枪的数据（战斗数值在这里）
- RigWeapons — 枪械动画
- Grenade — 手雷
- NpcCombat — NPC 遇敌：打还是躲
- NpcTactics — 幸存者小队战术
- Enemy + EnemyDefs + EnemyDirector — 敌人
- AbaForce + AbaSquad + AbaOperative — ABA 清除小组
- HitFx、BloodPools、Gibs — 着弹点 / 血迹 / 尸体爆炸

### 🧍 角色外观与动画（代码拼装角色）
- **CharacterRigBase**（+ 分部文件 .AK / .Bolt / .BoltReload / .Bullpup / .Draw / .Gib / .GunAnim / .Reload / .Throw）— 所有拼装角色的基类
- NpcRig — 防护服 NPC 外观
- NpcRigB（+ .Throw）— 头盔士兵外观（ABA）
- InfectedRig — 被感染的研究员
- SpiderRig — 骨骼动画怪物（眼球蜘蛛）

### 💡 光照 · 阴影 · 营地美术
- WorldLighting — URP 2D 全局光照
- RenderMats — 2D 光照材质工具
- SilhouetteShadows、GroundShadow — 剪影投影 / 脚下影子
- CampArt、CampProps、CampGate — 营地美术、摆设、升降杆大门

### 🖥️ UI / HUD
- **ChatManager** + **VirtualChatList** — 主聊天框（核心，改前先读懂）
- NpcChatWindow — NPC 专属对话窗口
- HudLayout、HudDock、HudToasts — HUD 布局 / 底部任务栏 / 右上角汇报
- ResourceHud、ArcGauge、SegmentDisplay — 资源栏 / 圆形刻度 / 电子表字体
- WeatherPanel、CellInfo、HoverInfo、UiPopup — 天气 / 位置 / 悬停 / 浮窗
- NpcTaskPanel、NpcListPanel、NpcCardUI、StatusPanelManager — 任务 / NPC 列表 / 状态卡
- EventLogManager、LogManager、LogClickHandler — 事件与行为日志
- **WorldClickRouter** — 场景点击统一入口（新东西实现 IWorldClick / IWorldInfo 接入）
- NpcClickable、NpcClickHandler（只剩标记作用）
- UiStyle — 「ABA 监控终端」统一样式
- CollapsibleSection — 折叠节
- CameraController — 镜头缩放 / 拖动 / 跟随
- MainMenuController — 主菜单

### 🌐 本地化
- **LocalizationManager** — 翻译表（UI 固定文字都走这里，不写死中文）
- LocalizedText — 跟随语言切换的文本组件

### 🧪 测试 / 调试工具
- DebugSanityPanel — SAN 与健康调节（F2）
- AiScheduler 调试面板 — F9
- CombatTest — 战斗测试场景逻辑
- AnimTestHub — 动画测试中心
- DemoController — 发表演示用
