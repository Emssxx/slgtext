## 4. 命名和存放规则

1. **文件名**：英文，单词首字母大写，下划线接变体。例：`Camp_Table_V_Blood.png`（`_V` = 竖向版本，`_Blood` = 带血版本）。
2. **代码要加载的图**放进 `Assets/Resources/<类别>Art/`；同一个对象的多个部件放进它自己的子文件夹（例：一把枪一个文件夹）。
3. **不被代码加载的图**（贴图、Tile）放进 `Assets/image/`。
4. **枪械素材**按 `Assets/Docs/ABA武装人员_武器素材.md` 的规范：十字线标注枪口和握持点，挂载图不缩小。
5. **新字体**必须附上许可文件（例：`CourierPrime-OFL.txt`）。
6. 原始 PSD 等源文件不放进 `Assets/`（Unity 会尝试导入）。要备份源文件，先和文件管理部商量放在哪。
