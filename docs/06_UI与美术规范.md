# 06 UI 与美术规范

## UI 风格（统一使用）
- 主色是**淡绿色加淡淡的发光**（参照 DS-Digital / 卡西欧电子表字体）。资源充足时用淡蓝色；不足时变淡黄色并不规则闪烁。背景板一律透明。
- **四角框**：只保留四个角的框。出现时四个角从中心平滑展开，大约 0.1 秒。悬停时带微弱的呼吸光。
- **浮窗动画**：从目标的左上角延伸出一条线 → 线移动到固定位置后变成水平，成为浮窗的上沿 → 浮窗从这条线向下展开。线要细。消失时四个角反向收回，背景板要跟着四个角同步收起。
- 小标题：左上角的淡绿色 debug 风格背景框（用英语）。
- 多个浮窗同时打开时不要互相遮挡，要并排或并列显示。
- 终端机、建造蓝图模式：老式电脑系统、命令行风格。
- 字体：Courier Prime（OFL）等。

## HUD 布局（现行）
- 天数：屏幕上方正中间，「数字 + DAY」，淡绿色发光。
- 电力、水和基础资源：左侧日志栏下方，从上到下排列，用图标 + 圆形格子刻度显示。
- 事件和日志：左上角，各自是独立的浮窗。
- 建造完成提示：右下角，用四角框动画。
- 坐标和地形：左下角，四角框常驻显示。
- 对话框：选中一个 NPC 后打开专属的竖长对话框。上方左边是 NPC 实时动画头像，右边是姓名、HP 等状态，下方是词条。对话框可以拖动。
- NPC 悬停浮窗：四角框，左上角显示姓名、正在做什么、生命、水分、健康（姓名放在淡绿色 debug 框里，不显示职业）。
- HP 联动：生命值越低，颜色越平滑地从绿过渡到黄再到红，故障抖动和电流闪烁也越来越强（闪烁是黄色和黑色交替）。死亡瞬间即使鼠标没有悬停也会弹出浮窗，加上划线效果。
- 快捷键：Y 键进入或退出对话模式，B 键进入建造模式。输入栏处于焦点时快捷键无效。点击 UI 时不能穿透到地图。

## 天气图标
- 雨：小雨是一滴倾斜的水滴，中雨两滴并排，大雨在两滴上方再加一滴。雪的排列方式相同。
- 风：用风向袋表示（圆锥形、中间有孔、带条纹），风越大越接近水平。
- 冰雹：空心六边形，中间加一片雪花。

## 美术（用户本人的手绘风格）
- 不再做像素风，改用**骨骼动画**（逐帧动画在角色复用时工作量太大）。
- 素材分层：身体 / 服装 / 饰品 / 挂件。表情不拆开五官，直接按表情整张绘制（老人、女性、男性三套）。发型分男女。PSD 的图层都已命名。
- 惯性运动：软管、拉链、挂件、水瓶都要做惯性摆动。跑步时手脚摆动遵循「慢—快—慢」的钟摆节奏，手脚到最高点时身体也在最高点。
- 面罩：自上而下展开，展开后有一道光横向移动，移动速度随走或跑变化。切换表情时面罩开合一次，奔跑时面罩关闭。
- 手部替换素材：持枪手、持斧手、持锤手、持医疗包手、持水瓶手。
- 地图素材：用户自己画了营地的铁丝网和地砖作为基准，其他素材请人模仿这个风格制作。
- AI 图像生成：ComfyUI（FLUX.1 dev fp8 / Wan2.2 i2v 14B fp8），用于场景概念图、角色插画、答辩用的氛围视频。
- 封面主视觉：「变异研究员」插画，以及据此制作的封面动画（瞳孔动画）。
