# 亚空间生存SLG — 事件篇 设计文档

> 本篇是所有「事件」的统一容器。**凡是有因有果的东西，都是事件**，都归这里。
> 事件篇定义「怎么触发、产生什么后果」（动词）；怪物长相/数值在【怪物篇】（名词）。
> 关联：核心设定_唯物对抗唯心.md、怪物篇、资源与材料_设定.md、结局篇。

## 一、事件的统一定义与设计模板

**事件 = 有「因」（触发条件）+ 有「果」（后果）的一次世界变化。**
这统一了过去「杂乱无章」的现象——一切现象都是某个因导致的果。

每个事件用以下模板定义：

```
事件名：
├─ 所属子类：自然 / 人为 / 随机 …
├─ 触发条件：什么情况下发生（异常度、情绪、设施状态、特定NPC状态…）
├─ 对NPC的影响：SAN/数值/行为的实际变化
├─ 对营地的影响：资源/设施/环境的变化
├─ 视觉表现：玩家看到什么
└─ 玩家决策：这个事件逼玩家做什么取舍
```

> 设计铁律：每个事件都要能**逼出一个玩家决策**，否则它只是刷文字。

## 二、事件子类（框架先搭，子类持续补充）

### 子类1：自然事件
- 亚空间自身的、非人为的能量/规律现象。
- **代表：亚空间风暴**（能量失控，参考太阳风暴）
  - 触发：异常度达阈值 / 导演判断施压。
  - 对营地：摧毁基地设施（机械、建筑类）。
  - 对NPC：设施被毁 → NPC 失去 SAN 保障（庇护）→ 暴露 → 掉 SAN
    （复用统一的「暴露掉SAN」机制，见核心设定·九）。
  - 视觉：能量风暴、设施受损特效、警告UI。
  - 玩家决策：抢修设施？把NPC撤入仍完好的庇护？牺牲哪块？

### 子类2：人为事件（人/AI 的状态或行为引发）
- 由 NPC 或 AI 机器人的状态/行为引发的事件。
- **代表：幻觉实体化**
  - 触发：某 NPC 幻觉/精神恶化到阈值。
  - 后果：其心魔实体化成【公共型怪物】（怪物长相见怪物篇）→ 威胁全营地。
  - 玩家决策：早点管这个NPC的精神（预防）？还是事后组织防御（补救）？
- **代表：NPC 崩坏（isBroken）**
  - 即现有的崩坏系统（脱离LLM、破碎呓语/转化）。作为「人为事件·私人」的一种，复用现有代码。
- **代表：AI 机器人 与 人类的冲突**（待补充）
  - 触发：机器人数量过多 / 机器人觉醒 / 信任过低。
  - 后果：NPC 离心、拒绝合作、甚至冲突。
- **代表：新增 NPC 相关事件**（待补充）
  - 新幸存者加入营地时应有相应事件（来历、营地反应、信任初始化…）。

### 子类3：随机事件（导演即兴生成）
- AI 导演从现有「事件素材库」即兴生成的各类异常。
- 现有导演提示词里的素材：不同年代的遗存、造物的掠影、空间扭曲、时间失序、
  因果倒置、负能量风暴、物资异变、低语与幻象。
- 这些撞见造物/幻觉/精神侵蚀类，对NPC的精神冲击 = SAN下降（复用统一机制）。
- 触发：导演根据世界状态（异常度、集体情绪）即兴决定。

## 三、事件与核心引擎的关系（终结「杂乱无章」）

- 所有事件，本质都是**亚空间对集体情绪 / 世界状态的反应**（见核心设定·情绪反馈引擎）。
- 因此事件不再是随机刷，而是「**当前局势招来的**」——有了内在逻辑。
- 导演 = 事件的总调度：观察局势，决定何时触发哪类事件、施加多大压力。
