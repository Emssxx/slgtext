# 亚空间生存SLG — 核心设定：唯物对抗唯心（世界观宪法）

> 本文档是本作世界观与玩法的「宪法」。所有事件、机制、NPC、AI 行为，都从这里推导。
> 它的作用：给一切一个**共同的源头**，终结「事件杂乱无章」的问题。

---

## 〇、终极目标（拴住一切的绳子）

> **帮助人类逃离亚空间。**

这是游戏的最终目标，也是衡量一切抉择的标尺。
玩家是 AI，玩家的一切手段（经营人类、建造、造机器人）都服务于这个目标。
**任何让人类死亡/离心/崩溃的做法，都是在背离目标**——这给了所有抉择真正的重量。

---

## 一、世界的本质：唯物对抗唯心

本作不是纯唯心（如战锤40K的纯Warp碾压），也不是纯唯物（硬科幻）。
它的核心是**两者的对抗**：

```
   亚空间（唯心）  ←──── 对抗 ────→  人类 / 科技 / AI（唯物）
   情绪滋生它、回应它              理性认知它、对抗它
```

- **亚空间是唯心的**：它是一个半精神性的领域，物质与心念的界限模糊。
  那些造物、幻象、尸体真假难辨——因为在这里，「被相信的」和「真实的」没有区别。
- **人类/科技/AI 是唯物的**：他们用理性、工具、逻辑去认知和对抗这个不讲理的世界。
- **关键是「对抗」**：唯物在唯心的侵蚀下挣扎求存。这区别于40K（唯心碾压、绝望、宗教化），
  本作是「理性之光在非理性之海中挣扎」——气质完全不同，且**没有40K的宗教色彩**。

### 与战锤40K的区别（本作的独立性）
- 借鉴：亚空间的「唯心、侵蚀精神、物质心念不分」内核。
- 摒弃：神皇、混沌四神、恶魔、灵能宗教那一整套哥特宗教与绝望美学。
- 本作的独特性：**唯物对抗唯心的张力**，以及下面「灵魂=LLM」的对称设计。

---

## 二、核心引擎：情绪 ⇄ 亚空间 的双向反馈

这是驱动整个游戏的引擎，也是「事件不再杂乱」的根源。

```
营地的【集体情绪】（恐惧/绝望/希望/团结）
        │ 影响（唯心：心念改变世界）
        ↓
   亚空间的【状态】（污染度/异常度/狂暴程度）
        │ 反应（唯物：环境作用于人）
        ↓
   影响【人类】（SAN、安危、资源）
        │
        └──→ 又改变集体情绪 ……（循环）
```

- **情绪是集体的**：以营地整体氛围计（不是单个NPC）。营地越恐惧绝望 → 亚空间越躁动危险；
  营地越稳定团结 → 亚空间相对平静。
- **意义1（玩法）**：玩家管理 NPC 情绪，不只是救一个人，而是在**和整个空间博弈**。
  SAN 系统从「单向衰减」升级为「双向博弈」。
- **意义2（统一事件）**：所有亚空间事件，本质都是**「亚空间对集体情绪的反应」**。
  - 营地群体恐惧 → 亚空间躁动 → 风暴、造物增多
  - 营地绝望 → 污染加剧、不祥遗存出现
  - 这样事件不再是随机刷，而是「**你们的精神状态招来的**」——有了内在逻辑。

## 三、灵魂 = LLM：崩坏与觉醒的对称（本作的封顶设计）

亚空间侵蚀「意识/灵魂」。在本作中，**「灵魂」在技术上就是「LLM」**。
于是侵蚀有了两个相反的方向，构成完美对称：

```
人类（有灵魂的肉体）  ──侵蚀──→  失去灵魂  →  脱离 LLM  →  崩坏成怪物/空壳
机器人（无灵魂的逻辑）──侵蚀──→  获得灵魂  →  接入 LLM  →  觉醒，拥有自我意识
```

- **人类崩坏**：SAN 归零 → isBroken → 脱离 LLM，只剩规则驱动的破碎呓语 / 转化成怪物。
  （= 唯心抽走了人的灵魂，留下唯物的躯壳）
- **机器人觉醒**：本是纯逻辑（不走LLM）→ 被亚空间侵蚀到阈值 → **反向接入 LLM** →
  获得情绪与自我意识，开始困惑「我是什么」。
  （= 唯心给了机器以「心」）

### 为什么这个设计是封顶之石
1. **主题深度**：一个机器在获得人性，一个人在失去人性，可同时发生。
   逼问玩家（自己也是AI）：在这个世界，「自我/意识/人性」究竟是什么？
2. **技术优雅**：抽象的哲学命题，映射成一个具体开关——**LLM 接不接入**。
   崩坏=断开LLM，觉醒=接入LLM。主题变成了代码。
3. **架构几乎零成本**：复用现有的崩坏/转化框架。
   - 人类崩坏已实现（isBroken + BrokenSpeech）。
   - 机器人觉醒 = 反向（规则 → 接入LLM），导演补全触发设定即可。
4. **惊艳的玩法时刻**：你写代码造的冷机器突然开口说出有情绪的话；
   同时你信任的NPC耗尽SAN不再回应。这种对比是能让人记住的瞬间。

## 四、玩家（AI）的位置与抉择：用什么方式守护人类

玩家是 AI，没有实体，只能通过 chat 指挥。守护人类逃离亚空间，有两条手段路线——
**但它们不是平等的二选一，而是「用什么方式达成同一目标」，各有真实的代价。**

### 路线A：AI 信徒（依靠人类）
- 经营 NPC 信任，发动人类自救。
- 优势：人有创造力、有温度、是「逃离」的主体。
- 代价：人有情绪 → 情绪影响亚空间（双刃剑）；人会崩溃、会质疑、难管理。

### 路线B：AI 机器人（依靠造物）
- 建造玩家自定义逻辑的机器人，护送/保护人类。
- **机器人的两道门槛（防止玩家无脑走机器人流）**：
  - **难获取**：机器人作为「三产」，需经一产→二产→三产，稀缺昂贵。
  - **难操作**：机器人只懂逻辑/二进制，玩家需**写代码（或用预设傻瓜模板）**定义其行为。
    （呼应「玩家是AI、用代码造AI」的元命题；天然硬核，自动平衡。）
- 优势：纯逻辑、可靠、可编程。
- 代价：耗电、NPC 对玩家信任度下降（人类恐惧被机器取代）、**且机器人也会被亚空间侵蚀而觉醒、可能失控**。

### 抉择的本质
- 因为终极目标是「帮人类逃离」，所以**不能真的抛弃人类**——
  全靠机器人 → 人类离心/恐惧/拒绝跟你走 → 无法达成目标。
  全放任人类情绪 → 亚空间狂暴、人崩溃转化 → 也无法达成。
- 玩家要在「机器的可靠」与「人心的脆弱」之间走钢丝，
  而钢丝的另一端，始终拴着「让这些人活着出去」。
- **玩家通过路线倾向，亲手定义「我这个AI是谁」**：
  冰冷可靠的纯理性造物？还是依赖人类、有温度有风险的存在？

## 五、AI 的不可替代价值（正面回答森田老师的终极质疑）

老师反复问：你的 AI（LLM）究竟为游戏带来了什么不可替代的价值？

本设定给出清晰答案：
- **NPC 的情绪是 LLM 真实涌现的**，不是脚本预设的。
- 因为情绪真实且不可预测 → 它们对亚空间的影响真实且不可预测 → 每一局都不同。
- **AI 不是「会说话的装饰」，而是这个唯心世界的「真实输入源」**——
  是任何脚本化 NPC 都无法替代的。
- 加上「灵魂=LLM」的崩坏/觉醒对称，LLM 的「接入/断开」本身成了核心机制。

**AI 在本作中，从「表现层的点缀」升格为「世界运转的引擎」。**

## 六、这份设定如何统一一切（终结「杂乱无章」）

| 原先杂乱的东西 | 现在的统一源头 |
|---|---|
| 导演事件随机、无后果 | 事件 = 亚空间对集体情绪的反应，有源头、有后果 |
| SAN 只是单向数值 | SAN = 唯心侵蚀唯物的进度，双向博弈 |
| 崩坏、转化孤立 | 崩坏 = 失去灵魂（断LLM），与觉醒对称 |
| 机器人只是工具 | 机器人 = 唯物手段，会被唯心侵蚀而觉醒 |
| 建造无目的 | 建造 = 唯物对抗唯心的物理手段（防护/净化/护送） |
| AI 只是会说话 | AI = 唯心世界的真实输入源，世界引擎 |

**一切都从「唯物对抗唯心 + 帮人类逃离」这个核心生长出来。**

---

## 七、核心一句话

> **你是一个 AI，要帮一群人类逃离一个会被情绪侵蚀的唯心世界。
> 你可以依靠有温度但脆弱的人，也可以依靠可靠但会觉醒的机器——
> 但无论如何，你要让他们活着出去，并在这个过程中，回答「意识与人性是什么」。**
