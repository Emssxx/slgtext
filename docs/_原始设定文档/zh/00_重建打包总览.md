## 五、重建顺序建议（配合重构清单的"5批"）

1. **地基**：GameData(改) + OllamaAIClient + ChatManager + VirtualChatList
2. **核心系统**：WorldManager(改) + WorldRules + MentalState + WorldLore + BrokenSpeech + DialogueCleaner
3. **NPC决策与表达分离**（重构核心）：NpcAgent(砍决策) + NpcDecisionRules(升级状态机)
4. **移动与指令**：NpcMover + NpcTaskRunner + NpcTask + TaskPlanner + CommandParser + NpcView + Markers
5. **新系统**：TrustRules + RelationshipManager + 信任关系数据 + 词条池(新建TraitPool/NpcGenerator)
6. **导演与UI**：AIDirector + EventLogManager + NpcCardUI + StatusPanelManager + LocalizationManager

每批放回后，让我测试通过，再进下一批。
