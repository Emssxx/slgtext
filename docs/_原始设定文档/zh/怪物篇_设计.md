# 亚空间生存SLG — 怪物篇 设计文档

> 本文档定义游戏中的「亚空间生物（怪物）」。
> 所有怪物都从核心设定「唯物对抗唯心」推导而来，不是孤立的刷怪点。
> 关联文档：核心设定_唯物对抗唯心.md、资源与材料_设定.md、事件篇。

---

## 一、怪物的两大类（各对应核心的一个方向）

亚空间的怪物只有两大类，分别对应「唯物对抗唯心」的两个方向：

### 第一类：腐蚀外来种（唯物的人 → 被唯心同化）
- **来源**：先前进入亚空间的科研队员（ABA 的前批调查者）等外来者，被亚空间长期腐蚀，怪物化。
- **本质**：原本是「唯物的人」，被唯心的亚空间侵蚀、同化，失去人性，变成怪物。
- **呼应核心**：与「人类崩坏 = 失去灵魂（脱离LLM）」同源——这是腐蚀的终点形态。
- **气质**：曾经是人，如今扭曲。残留一些人类的痕迹（装备、姿态），更显悲凉与恐怖。

### 第二类：幻觉实体化（唯心直接造物 / 克苏鲁 · 墨菲定律）
- **来源**：NPC 的幻觉、心魔，在唯心的亚空间里**实体化**成真实的怪物。
- **本质**：唯心直接把「精神」变成「实体」——情绪/恐惧/幻觉凝结成怪。
- **呼应核心**：直接体现「亚空间是唯心的、物质与心念不分」。也呼应「墨菲定律」——
  越害怕的东西，越会成真。
- **气质**：无法名状、克苏鲁式，形态源于 NPC 内心最深的恐惧，因人而异。

> 这两类各接「唯物对抗唯心」的一根：一类是唯物被唯心吞噬，一类是唯心凭空造物。
> 仅这两类，衍生出的具体怪物种类已足够丰富。

---

## 二、幻觉实体化怪物 × 情绪反馈引擎（强耦合）

第二类怪物与核心引擎「情绪 ⇄ 亚空间」强耦合，是重要的玩法节点：

- NPC 幻觉严重 → 其心魔**实体化成怪** → 对营地构成威胁。
- 这让「管理单个 NPC 的精神」有了**硬性玩法理由**：
  不管他 → 他的心魔变成实体 → 咬死大家。
- **一个人的崩溃会连累所有人** —— 戏剧张力极强。

### ⚠️ 待定决策点：幻觉怪是「私人心魔」还是「公共威胁」？
- **方案A（私人心魔）**：实体化的怪只针对/只能伤害那个 NPC 本人。
  - 较轻，聚焦个人悲剧。
- **方案B（公共威胁）**：心魔实体化后威胁全营地。
  - 较重，「一人崩溃连累全员」，迫使玩家必须关注每个人的精神。
  - 玩法重量更大，与「不能把 NPC 当螺丝」的设计哲学一致。
- **倾向**：待定，但 B 与核心玩法（管理情绪、善待每个NPC）更咬合。

## 三、怪物与资源的关系（连接资源篇）

- 击杀亚空间生物 → 获得资源（蛋白质营养物 / 亚空间提取液等，见资源篇）。
- 因为怪物 = 唯心造物或被同化者，所以「击杀获取资源」在设定上自洽：
  **人类（唯物）靠消耗「唯心的造物」维生。**
- ⚠️ 潜在张力（待事件篇/数值篇权衡）：
  若「营地恐惧 → 幻觉怪增多 → 食物增多」，可能诱导玩家故意制造恐惧。
  需通过「怪物危险度 > 食物收益」等方式平衡，避免玩家找到「反核心」最优解。
