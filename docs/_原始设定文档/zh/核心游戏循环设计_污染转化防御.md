# 亚空间生存SLG — 核心游戏循环设计（污染·净化·转化·防御·怪潮）

> 本文档把「污染→净化→转化→防御→怪潮」五个机制，设计成一个由 **AI 导演调度** 的完整游戏循环。
> 核心原则：**保住 AI 核心**——这些机制是「AI 导演制造问题」的手段，而非把游戏变成普通塔防。
> 参考：《缺氧》（环境/资源管理）、《亿万僵尸》（防御波次），但用 AI 导演驱动，做出独有体验。

---

## 一、设计的出发点：回答「玩家在做什么」

森田老师从企划书起反复追问：**游戏的乐趣在哪？玩家会不会无聊？**

这套循环正面回答它：玩家在任意时刻都有意义的决策要做——
- 监控哪个区域在污染、有多严重；
- 决定建净化装置（建哪、先建哪）；
- 管理 NPC 的 SAN（谁该撤离污染区、谁该休息）；
- 防止 NPC 被转化（盯住低 SAN 的人）；
- 建防御、备武器，应对怪物与怪潮。

玩家从「指挥几个 NPC 搬箱子」升级为「在持续恶化的环境里做生存权衡」。

---

## 二、核心原则：AI 导演是「问题的导演」，不是固定刷新

这是本设计与普通塔防的根本区别。

| | 普通塔防 | 本作（AI 导演调度） |
|---|---|---|
| 怪潮 | 第10分钟固定刷20只 | 导演观察局势，针对玩家弱点制造威胁 |
| 污染 | 固定区域固定速度 | 导演决定何时让哪个区域恶化 |
| 转化 | 随机 | 导演挑「最有戏剧性/最痛」的那个 NPC |

**例子**：导演观察到「玩家把 NPC 都派去东边建造、西边空虚、3号 NPC 的 SAN 只剩 15」
→ 决定「让西边污染骤增，把 3 号转化成怪，从西边内部爆发」
→ 玩家措手不及，要紧急应对。

这正是之前定下的「AI 导演超越 RimWorld 抽签讲述者」的具体落地：
**不是从事件池抽签，而是针对玩家当前处境即兴生成最有效的『问题』。**

## 三、完整循环：五个机制如何咬合

```
        ┌──────────── AI 导演（总调度·核心）────────────┐
        │  观察局势 → 决定 何时/何地：污染加剧、转化谁、刷怪潮  │
        └───────┬──────────────┬──────────────┬────────┘
                ↓              ↓              ↓
        ① 污染加剧        ③ 转化 NPC        ⑤ 刷怪潮
                ↓              ↓              ↓
   ┌─ 环境层 ─────┐  ┌─ 危机层 ─────┐  ┌─ 对抗层 ──────┐
   │ 区域污染度↑   │  │ NPC SAN归零   │  │ 怪物潮来袭     │
   │ 靠近狂掉SAN   │  │ → 转化成怪物   │  │ （亿万僵尸式）  │
   └──────┬──────┘  └──────┬──────┘  └──────┬───────┘
          ↓                ↓                ↓
   ┌──────────────── 玩家应对 ────────────────────┐
   │ ② 建净化装置降污染 / 指挥NPC撤离 / 管理SAN       │
   │ ④ 建防御建筑 / 备武器 / 组织防守               │
   └──────────────────────────────────────────────┘
```

## 四、各机制设计

### 机制1：空间化的 SAN 威胁（污染区域）
- **是什么**：地图按区域（或格子）有「污染度」数值。NPC/玩家关注点靠近高污染区 → SAN 加速下降。
- **从哪来**：把现有 SAN 系统从「随时间衰减」升级为「随空间位置衰减」。SAN 机制本身已存在，这里只是改「衰减的触发条件」。
- **导演接口**：导演可以提升指定区域的污染度（制造问题）。
- **玩家可见**：地图上污染区用颜色/雾效标示，让玩家一眼看出「哪里危险」。

### 机制2：净化装置（玩家的对抗手段）
- **是什么**：一种建造物，放置后持续降低周围区域的污染度。
- **连回建造系统**：这给了建造系统一个**真实的生存目的**（之前建墙建箱子目的模糊，现在建净化器是为了活命）。
- **设计要点**：净化装置应消耗某种资源/能量（制造取舍：玩家不能无限净化，要选「先净化哪」）。
- **数据驱动**：用现有的 BuildableData 加一种「净化装置」即可（category 加一项 Purifier）。

### 机制3：SAN 归零 → 转化怪物（升级崩解系统）
- **是什么**：NPC SAN 归零，不再只是「崩解+异变+可能死亡」，而是**转化成敌对怪物**。
- **从哪来**：升级现有的崩解系统（isBroken/mutations 已存在）。转化 = 崩解的「最终形态」：脱离玩家控制、变成威胁。
- **戏剧性**：玩家眼睁睁看着有名字、有性格、对话过的同伴变成怪物——**情感冲击 + 玩法威胁双重**。这是叙事和玩法的结合点，是本作的高光。
- **导演接口**：导演可以「推一把」让濒临崩溃的 NPC 转化（在最有戏剧性的时刻）。

### 机制4：防御机制（武器 / 防御建筑）
- **是什么**：应对转化的怪 + 野生怪 + 怪潮。手段包括武器（NPC 持武器战斗）、防御建筑（炮塔/陷阱/墙）。
- **连回建造系统**：防御建筑用建造系统做（墙已经能挡路，再加「会攻击的防御物」）。
- **⚠️ 最大的复杂度在这里**：战斗系统是全新的大模块（怪物AI、攻击判定、血量、武器）。需要选**最轻量**的方案（见第六节危险决策点）。

### 机制5：怪潮事件（AI 导演的杀手级应用）
- **是什么**：导演在合适时机刷新大规模怪物潮，玩家组织防御战（亿万僵尸式）。
- **为什么是导演的杀手级应用**：怪潮不是固定刷新，而是导演**针对玩家当前防御薄弱处、在最难受的时机**发动。这让导演从「讲故事的」变成「有獠牙的对手」。
- **节奏**：怪潮应是「偶尔的高潮」，不是「持续的主旋律」（见调性平衡）。

## 五、与现有系统的衔接（不是凭空加，是复用升级）

| 新机制 | 复用/升级的现有系统 |
|---|---|
| 污染区域 | SAN 系统（衰减条件：时间 → 空间） |
| 净化装置 | 建造系统 + BuildableData（加一种建造物） |
| 转化怪物 | 崩解系统 isBroken/mutations（崩解 → 转化） |
| 防御建筑 | 建造系统（墙已能挡，加会攻击的） |
| 怪潮调度 | AI 导演（现有导演加「制造威胁」的能力） |

**关键**：五个机制几乎都接在已有系统上，不是从零造五个新系统。这降低了实现风险。

## 六、危险决策点（做不好会翻车，需要权衡）

### ⚠️ 1. 调性平衡：别变成普通塔防
- 风险：打怪/防御一旦成为主旋律，会压过「AI 叙事/人性」这个核心卖点，游戏就和普通塔防拉不开差距。
- 对策：**控制怪物出场频率**。怪潮是「偶尔的高潮」，大部分时间游戏仍是「污染管理 + NPC 对话 + 精神博弈」。怪物是叙事张力的爆发点，不是持续的射击场。

### ⚠️ 2. 战斗系统的复杂度（最大的坑）
- 战斗是全新大模块：怪物AI、攻击判定、血量、武器、NPC 战斗行为。
- 对策：选**最轻量**方案。建议：
  - 怪物用简单规则AI（朝最近的 NPC/建筑移动并攻击），不走 LLM。
  - NPC 战斗用「自动反击」（靠近怪物自动攻击），玩家通过「指挥站位/撤退」参与，而非微操打怪。
  - 先做「防御建筑自动攻击」（炮塔），比「NPC 持武器战斗」更简单。

### ⚠️ 3. 这些机制必须由导演驱动，否则失去意义
- 如果污染/转化/怪潮都做成固定规则刷新，就是普通塔防，浪费了 AI 核心。
- 对策：每个机制都留「导演接口」，让导演能调度它们。导演是总指挥。

### ⚠️ 4. 工作量：不可能一次做完
- 这是数月的工作量。必须分期，每期都「可玩、可验证」。

## 七、分期实现路线（每期都要可玩可验证）

> 原则：先做「最小可玩的循环」，验证好不好玩，再逐步加深。不要一次全做。

**第 0 期（先于一切）：垂直切片验证 ★强烈建议**
- 不加新机制，先把【现有系统】串成一个最小循环自己玩一遍：
  导演丢事件 → 对话了解 → 指挥NPC应对 → 看NPC因信任/精神不完全配合 → 结果。
- 目的：先确认「现有的核心」好不好玩，再决定新机制怎么加。
- 这是回答老师质疑的第一步，也避免在没验证的基础上盖更多楼。

**第 1 期：空间化污染 + 净化（最小、复用最多）**
- 机制1（区域污染→空间SAN威胁）+ 机制2（净化装置）。
- 复用 SAN 系统和建造系统，新代码最少。
- 验证：玩家要不要管污染？建净化器有没有「生存压力」的感觉？
- **这一期就能让游戏「有事做」**，且不引入战斗的复杂度。

**第 2 期：转化怪物（升级崩解，先不做战斗）**
- 机制3：SAN归零的NPC转化成怪物（先只做「变成敌对、会乱跑、靠近掉SAN」，暂不做战斗）。
- 验证：「同伴变怪」的情感冲击和威胁感成立吗？

**第 3 期：防御（引入轻量战斗）**
- 机制4：先做最简单的防御建筑（自动攻击的炮塔）+ 怪物简单AI。
- 验证：防御玩法成立吗？复杂度可控吗？

**第 4 期：怪潮 + 导演调度（整合，点亮核心）**
- 机制5：导演刷怪潮 + 把污染/转化/怪潮都接上导演的「制造问题」逻辑。
- 这一期点亮整个设计的灵魂：AI 导演成为针对玩家的总调度。

---

## 八、一句话总结

把《缺氧》的环境管理和《亿万僵尸》的防御波次，**作为 AI 导演制造问题的武器库**，
让导演针对玩家处境即兴制造「污染—转化—怪潮」的连锁危机。
玩家忙于净化、管理精神、组织防御——**既回答了「玩家在做什么」，又强化了 AI 这个核心卖点**。

**但务必：先做第0期垂直切片，验证现有核心好不好玩，再逐期加深。**
