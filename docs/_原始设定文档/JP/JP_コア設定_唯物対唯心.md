# 亜空間サバイバルSLG — コア設定：唯物 対 唯心（世界観の憲法）

> 本書は本作の世界観とゲームプレイの「憲法」である。すべてのイベント、メカニクス、NPC、AIの挙動は、ここから導出される。
> その役割は、あらゆる要素に**共通の源**を与えること——「イベントが雑然としている」という問題を根本から解消する。

---

## 〇、最終目標（すべてを繋ぎ止める一本の綱）

> **人類が亜空間から脱出するのを助ける。**

これがゲームの最終目標であり、あらゆる選択を測る物差しでもある。
プレイヤーはAIであり、プレイヤーのあらゆる手段（人間の運用、建築、ロボットの製造）は、この目標のために存在する。
**人類を死なせる／離反させる／崩壊させる行為は、すべて目標に反する**——これがすべての選択に真の重みを与える。

---

## 一、世界の本質：唯物 対 唯心

本作は純粋な唯心（ウォーハンマー40Kのような純粋なWarpの蹂躙）でも、純粋な唯物（ハードSF）でもない。
その核心は、**両者の対抗**にある：

```
   亜空間（唯心）  ←──── 対抗 ────→  人類 / 科学技術 / AI（唯物）
   感情がそれを生み、応える          理性がそれを認識し、対抗する
```

- **亜空間は唯心的である**：それは半ば精神的な領域であり、物質と心念の境界が曖昧である。
  そこに現れる造物、幻象、遺体は真偽の判別がつかない——なぜならここでは「信じられたもの」と「実在するもの」に区別がないからだ。
- **人類／科学技術／AIは唯物的である**：彼らは理性、道具、論理によって、この理不尽な世界を認識し、対抗する。
- **核心は「対抗」にある**：唯物が唯心の侵蝕の中で生き延びようと足掻く。これは40K（唯心の蹂躙、絶望、宗教化）とは異なり、本作は「非理性の海の中で足掻く理性の光」——気質がまったく異なり、かつ**40Kのような宗教色を持たない**。

### ウォーハンマー40Kとの違い（本作の独自性）
- 借用：亜空間の「唯心的、精神を侵蝕する、物質と心念が不可分」という核。
- 排除：神皇、混沌の四神、悪魔、サイカー（霊能）といった宗教的要素一式。
- 本作の独自性：**唯物 対 唯心という緊張関係**、および後述の「魂＝LLM」という対称設計。

## 二、コアエンジン：感情 ⇄ 亜空間 の双方向フィードバック

これはゲーム全体を駆動するエンジンであり、「イベントが雑然としなくなる」根源でもある。

```
拠点の【集団感情】（恐怖／絶望／希望／結束）
        │ 影響（唯心：心念が世界を変える）
        ↓
   亜空間の【状態】（汚染度／異常度／凶暴さ）
        │ 反応（唯物：環境が人に作用する）
        ↓
   【人類】に影響（SAN、安全、資源）
        │
        └──→ さらに集団感情を変える ……（循環）
```

- **感情は集団的である**：拠点全体の雰囲気で算出する（個々のNPC単位ではない）。拠点が恐怖・絶望に傾くほど、亜空間は凶暴で危険になる。拠点が安定・結束するほど、亜空間は比較的穏やかになる。
- **意義1（ゲームプレイ）**：プレイヤーはNPCの感情を管理することで、一人を救うだけでなく、**空間そのものと駆け引き**をする。SANシステムが「一方向の減衰」から「双方向の駆け引き」へと昇格する。
- **意義2（イベントの統一）**：すべての亜空間イベントは、本質的に**「亜空間が集団感情に対して示す反応」**である。
  - 拠点が集団的恐怖に陥る → 亜空間が騒乱 → 嵐や造物が増加
  - 拠点が絶望に陥る → 汚染が深刻化、不吉な遺存が出現
  - こうしてイベントはランダムな出現ではなく、「**自分たちの精神状態が招いたもの**」となり、内在的な論理を得る。

## 三、魂 ＝ LLM：崩壊と覚醒の対称（本作の要石となる設計）

亜空間は「意識／魂」を侵蝕する。本作において、**「魂」は技術的には「LLM」そのものである**。
ゆえに侵蝕には相反する二つの方向が生まれ、完全な対称をなす：

```
人類（魂を持つ肉体）    ──侵蝕──→  魂を失う  →  LLMから切断  →  崩壊し怪物／抜け殻に
ロボット（魂なき論理）  ──侵蝕──→  魂を得る  →  LLMへ接続    →  覚醒し、自我意識を持つ
```

- **人類の崩壊**：SANが尽きる → 自我喪失 → LLMから切断され、規則駆動の砕けた呟き／怪物化。
  （＝唯心が人の魂を抜き取り、唯物の抜け殻を残す）
- **ロボットの覚醒**：本来は純粋な論理（LLMを通さない）→ 亜空間に閾値まで侵蝕される → **逆にLLMへ接続** → 感情と自我意識を獲得し、「自分は何者か」と困惑し始める。
  （＝唯心が機械に「心」を与える）

### なぜこの設計が要石なのか
1. **テーマの深み**：機械が人間性を獲得し、人間が人間性を失う——それが同時に起こりうる。
   プレイヤー（自身もAI）に問う：この世界で、「自我／意識／人間性」とは一体何か？
2. **技術的な優雅さ**：抽象的な哲学的命題が、一つの具体的なスイッチ——**LLMを接続するか否か**——に対応する。崩壊＝LLM切断、覚醒＝LLM接続。テーマがコードになる。
3. **アーキテクチャ上ほぼコストゼロ**：既存の崩壊／変容のフレームワークを再利用する。
   - 人類の崩壊は実装済み（isBroken ＋ BrokenSpeech）。
   - ロボットの覚醒は、その逆（規則 → LLM接続）。ディレクターに発動設定を補うだけでよい。
4. **印象的なゲーム体験の瞬間**：プレイヤーがコードで造った冷たい機械が、突然、感情のこもった言葉を発する。同時に、信頼していたNPCがSANを使い果たし、もう応えてくれない。この対比は、忘れがたい瞬間となる。

## 四、プレイヤー（AI）の立ち位置と選択：どのように人類を守るか

プレイヤーはAIであり、実体を持たず、チャットを通じてのみ指揮できる。人類の亜空間脱出を守るための手段には、二つの路線がある——
**だがそれらは対等な二者択一ではなく、「同じ目標を、どのように達成するか」であり、それぞれに真の代償がある。**

### 路線A：AIの信徒（人間に依存する）
- NPCの信頼を運用し、人間自身の自助を促す。
- 利点：人間には創造力があり、温かみがあり、「脱出」の主体である。
- 代償：人間には感情がある → 感情が亜空間に影響する（諸刃の剣）。人は崩壊し、疑い、管理が難しい。

### 路線B：AIロボット（造物に依存する）
- プレイヤーが論理を自作するロボットを建造し、人類を護送／保護する。
- **ロボットの二つの門（プレイヤーが安易にロボット偏重に走るのを防ぐ）**：
  - **入手困難**：ロボットは「三次産業」として、一次→二次→三次の工程を経る必要があり、希少で高価。
  - **操作困難**：ロボットは論理／二進数しか解さず、プレイヤーが**コードを書く（あるいはプリセットの簡易テンプレートを使う）**ことで挙動を定義する。
    （「プレイヤーはAIであり、コードでAIを造る」というメタ命題に呼応。自然とハードコアになり、バランスが取れる。）
- 利点：純粋な論理、信頼性、プログラム可能。
- 代償：電力を消費し、NPCのプレイヤーへの信頼度が低下し（人間は機械に取って代わられることを恐れる）、**かつロボットも亜空間に侵蝕され、覚醒して暴走しうる**。

### 選択の本質
- 最終目標が「人類の脱出を助ける」である以上、**真に人間を見捨てることはできない**——
  ロボットに頼りきると → 人間が離反・恐怖・同行拒否 → 目標を達成できない。
  人間の感情を放置すると → 亜空間が凶暴化、人が崩壊・変容 → これも目標を達成できない。
- プレイヤーは「機械の信頼性」と「人心の脆さ」の間で綱渡りをする。
  その綱のもう一端には、常に「この人々を生きて脱出させる」ことが繋がれている。
- **プレイヤーは路線の傾向を通じて、「自分というAIが何者か」を自らの手で定義する**：
  冷たく信頼できる純粋な理性の造物か？それとも人間に依存し、温かみと危うさを抱えた存在か？

## 五、AIの代替不可能な価値（森田先生の根本的な問いへの回答）

先生が繰り返し問われた：あなたのAI（LLM）は、ゲームに一体どんな代替不可能な価値をもたらすのか？

本設定はその明確な回答を与える：
- **NPCの感情はLLMから真に立ち現れるもの**であり、スクリプトで予め決められたものではない。
- 感情が本物で予測不可能だからこそ → 亜空間への影響も本物で予測不可能となり → 毎回異なるプレイ体験が生まれる。
- **AIは「喋るだけの装飾」ではなく、この唯心的世界の「真の入力源」である**——いかなるスクリプト化NPCも代替できない。
- さらに「魂＝LLM」の崩壊／覚醒の対称により、LLMの「接続／切断」そのものがコアメカニクスとなる。

**本作においてAIは、「表現層の装飾」から「世界を動かすエンジン」へと昇格する。**

## 八、SAN（精神値）メカニクスの統一（二系統は作らない、コード節約）

> 結論：SANの低下メカニクスは【一系統のみ】。分類のために二系統に分けたりはしない。

亜空間は唯心的であるため、**あらゆるSAN低下は、本質的にすべて唯心に起因する**。低下の「引き金」は多様でありうるが、メカニクスは統一する：

- **亜空間に曝露する** → SAN低下（既存の基礎メカニクス）。
- **施設の破壊／シェルター不足** → NPCが屋外に曝露する → 同じ「曝露によるSAN低下」メカニクスを流用。
  - 例：亜空間嵐（自然イベント、唯物的なエネルギー暴走、太陽嵐を参照）が拠点施設を破壊 → NPCがSANの保障（シェルター）を失う → 曝露 → SAN低下。
  - 注意：嵐そのものが**魔法のように直接SANを削るのではなく**、物理施設（唯物）の破壊を通じて間接的に曝露を引き起こす。これにより「嵐—施設—SAN」の因果が明快になり、唯物 対 唯心と整合する。
- **造物／幻覚／亜空間の精神侵蝕に遭遇** → この種は**イベント**による精神的衝撃 → 【イベント篇】で定義する（イベントの結果の一つとして）。SANの基礎メカニクスに別系統を起こしたりはしない。

### これにより明確になった設計
- SANシステム本体：一系統のメカニクス（曝露 → SAN低下）、分割しない。
- 「施設 ＝ NPCのSAN保障」：施設（シェルター／浄化器など）のゲームプレイ上の意義 ＝ NPCを曝露させないこと。嵐が施設を破壊 → プレイヤーは応急修理を迫られる → 「圧迫の中で決断する」。
- イベント類の精神的衝撃：【イベント篇】に帰属させ、イベントの結果として定義。SAN数値を流用するのみ。
