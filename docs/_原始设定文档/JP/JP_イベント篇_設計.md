# 亜空間サバイバルSLG — イベント篇 設計書

> 本書はすべての「イベント」を統括する。**因果のあるものは、すべてイベントである**とし、ここに帰属させる。
> イベント篇は「どう発動し、どんな結果を生むか」（動詞）を定義する。怪物の外見／数値は【怪物篇】（名詞）に置く。
> 関連：コア設定_唯物対唯心、怪物篇、資源・素材設定、エンディング篇。

---

## 一、イベントの統一定義と設計テンプレート

**イベント ＝ 「因」（発動条件）＋「果」（結果）を持つ、世界の一度の変化。**

### 設計テンプレート（簡潔版）
```
イベント名：
├─ 所属サブ分類：自然 / 人為 / ランダム / 探索遭遇 …
├─ 本質：一言で「これが何か」を述べる
├─ 発動条件：どんな状況で起こるか
├─ 主な影響対象：何に影響するか（NPC／建築／機械／電力／資源…）
├─ 視覚表現：プレイヤーに何が見えるか
└─（具体的な影響数値 → 数値篇；システム横断の連鎖 → 該当篇）
```

### 二つの鉄則
1. **客観的に記述し、プレイヤーの決断を予測しない**：イベントは「客観的に何が起きたか」だけを提示し、プレイヤーがどう対応するかは完全にプレイヤーに委ねる。「プレイヤーは～すべき」とは書かない。
   （理由：プレイヤーごとに考えは異なる。決断を予め定めると、自由度を制限し、AI駆動の自由を損なう。）
2. **各篇は越境しない**：イベント篇は「何に影響するか」を述べる。影響量は数値篇、電力の連鎖は電力篇、怪物の外見は怪物篇。各々が一区切りを担う。

> 検証方法：客観的に記述 → MVPを作る → 多様な人にプレイしてもらう → アンケート集計 → それに基づき最適化。
> 面白いかどうかは実際のプレイヤーの投票で決まり、文書上の想定には頼らない。

## 二、イベントのサブ分類（枠組みは構築済み、継続的に補充）

- **自然イベント**：亜空間自身の、人為によらない現象（嵐、空間歪曲、時間錯誤、因果倒置、囁きと幻象）
- **人為イベント**：人／AIの状態や行動が引き起こす（幻覚の実体化、NPC崩壊、AIロボットと人間の衝突、新規NPCイベント…）
- **ランダムイベント**：ディレクターが即興生成する雰囲気系
- **探索遭遇**：NPCがマップを探索する際に発動（異なる年代の遺存…）
- サブ分類は継続的に補充

## 三、定義済みのイベント（MVPで使用可能）

### 【自然イベント】亜空間嵐
- **本質**：亜空間のエネルギーが異常に噴出する現象。
- **発動条件**：anomalyLevel が閾値に到達／ディレクターが圧力をかけると判断。
- **主な影響対象**：建築類、機械類、電力システム。NPCへは非直接（太陽嵐になぞらえる。緩衝があり、せいぜい軽い不調程度）。
- **視覚表現**：エネルギーの奔流のエフェクト；電力／機械施設の過負荷、明滅、警告。
- *(影響数値 → 数値篇；電力の連鎖 → 電力篇)*

### 【自然イベント】空間歪曲
- **本質**：亜空間の空間構造が錯乱し、生存者が突如別の場所に現れる（体験＝ワープ）。
- **発動条件**：anomalyLevel が閾値に到達／ディレクター判断。
- **主な影響対象**：影響を受けるNPCの位置と精神／行動。
- **実装方法**：NPCとその全データを保持したまま、位置のみをマップ上のランダムな立ち入り可能地点へワープさせる（削除・再生成はせず、データ消失を防ぐ）。
- **ワープ後の反応**：ワープしたNPCは困惑または恐慌に陥り（強度は勇気の数値に影響される——勇気が高ければ冷静、低ければより恐慌。具体は数値篇）、現在のタスクを中断する。
- **視覚表現**：消失／出現のワープエフェクト、または空間の裂け目の感覚（暫定）。
- *(影響範囲／確率／感情数値 → 数値篇)*

### 【自然イベント】時間錯誤
- **本質**：亜空間の時間規律が狂い、時間感覚が錯乱する。メカニクス上は、ゲーム内時間の異常な早送りとして表現される。
- **発動条件**：anomalyLevel が閾値に到達／ディレクター判断。
- **前提依存**：UIにゲーム内時間（時計／日数）を表示する必要がある。さもなければプレイヤーは本イベントを感知できない。
- **主な影響対象**：ゲーム内時間（早送りのみ、巻き戻しはしない）。
- **実装方法**：UIの時計が約1秒の「故障／破損」アニメーションを再生（プレイヤーに気づかせる）した後、ゲーム内時間を前方へ早送りする。**早送りのみ、決して巻き戻さない**（プレイヤーの挫折感を避ける＋巻き戻しは実装が複雑でバグを生みやすい）。早送りは、飛ばした時間帯の消耗（空腹／SAN／異常度など）もまとめて計算する → 具体は数値篇。
- **視覚表現**：時計の故障／破損アニメーション；（任意）早送りに伴う空の色／光の急変。
- *(早送り量／発動確率／消耗計算 → 数値篇)*

### 【自然イベント】因果倒置（遅延イベント）
- **本質**：因果の対応関係が乱れる。乱れた「因」で造った「果」は、虚偽で不安定である。
- **発動条件**：anomalyLevel が閾値に到達／ディレクター判断。
- **主な影響対象**：建築類・道具類の必要素材、およびイベント期間中に造られた成果物。
- **イベント期間中**：建築／道具の必要素材が改竄される（例：防御壁 装甲板4 → 生物タンパク4）。これに乗じて建造するか否かはプレイヤーの裁量。期間前に完成した旧建築、および建造中のものは影響を受けない（イベント期間中に丸ごと新造したもののみが対象）。
- **イベント終了後**：「イベント期間中に新造された成果物」のみ、ランダム確率（→確率篇）で：機能停止／破壊 / 無影響 / 怪物化（→怪物篇）が発生する。
- **感知の手がかり**：イベント期間中、カメラに全画面フィルターをかけ（効果は暫定）、プレイヤーが「因果倒置の状態にある」ことを直感的に感知できるようにする。
- *(素材改竄の規則、各結果の確率 → 確率篇／数値篇；怪物化の形態 → 怪物篇)*

### 【探索遭遇】異なる年代の遺存
- **本質**：NPCが探索中に、この時代のものではない遺体／遺物に遭遇する。
- **発動条件**：NPCがマップを探索する際、確率で発動。
- **主な影響対象**：発見したそのNPCのSAN値（異様な光景に遭遇した衝撃）。
- **視覚表現**：暫定／既存の表現を流用。
- *(SAN低下量、発動確率 → 数値篇／確率篇)*

### 【自然イベント・公共】囁きと幻象（叙事的価値が最も高い）
- **本質**：拠点で誰かが存在しない囁きを聞き始める、あるいは既に死んだ者を見る。
- **発動条件**：ランダムに発動。
- **表現**：囁きの効果音 ＋ 影響を受けたNPCの反応。
- **会話可能な幻象 —— 二つの典型**：
  - **先遣隊員（世界観への入口）**：死の直前の人格を保持している。まず自分が本当に死んだのかを疑い →【確認】先遣隊員として、プレイヤーと会話し、自分の知っていることを語る（世界観を知る）；【否認】プレイヤーが説得するか、イベント終了とともに自ら消える。
  - **死んだNPC（魂の再登場・日常の演出）**：プレイヤーを責めない。生前のように他のNPCと会話し（次のタスクのこと、これからどうするか）、友人（信頼度の高い者）がいれば友人を訪ねる。「彼はまだ自分が死んだことを知らない」という落差によって、余白を残してプレイヤーの心を打つ。
- **視覚的区別**：幻象NPCと生きているNPCは美術的に区別する（プレイヤーが一目で見分けられるように）。
- **生きているNPCの反応**：生きているNPCは死者の幻象に反応する。信頼度に関わる（→信頼度篇、後述）。
- *(精神への影響数値、発動確率 → 数値篇／確率篇)*

## 四、処理済みのディレクター素材（転用 / 削除）

- **造物の影 → 怪物へ転用**：イベントとしては特定NPCのSANを削るだけで、冗長かつゲームプレイへの貢献が小さい。速度が極めて速く、拠点／NPCの周囲に出没する怪物「影」へ変更。詳細は怪物篇。
- **物資の異変 → 削除**：意義が小さく（純粋に物資を減らすのは反感を買いやすい）、ゲームプレイ上の価値がない。

## 五、イベントとコアエンジンの関係（「雑然」の終結）

- すべてのイベントは、本質的に**亜空間が集団感情／世界状態に示す反応**である（コア設定・感情フィードバックエンジン参照）。
- イベントはランダムな出現ではなく、「現在の局面が招いたもの」となり、内在的論理を得る。
- ディレクター ＝ イベントの総指揮：局面を観察し、いつ・どの種類のイベントを発動し、どれだけの圧力をかけるかを決定する。
