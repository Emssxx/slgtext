# 亜空間サバイバルSLG — 怪物篇 設計書

> 本篇は【怪物そのもの】のみを定義する：外見、数値、挙動。すなわち「名詞」である。
> 怪物が【どう発動／どう出現するか】は【イベント篇】で定義する（そちらが「動詞」）。
> 関連：コア設定_唯物対唯心、イベント篇、資源・素材設定。

---

## 一、怪物の二大分類（各々がコアの一方向に対応）

### 第一分類：腐蝕した外来種
- **設定上の由来**：以前に亜空間へ入った調査隊員（ABAの前バッチの調査者）などの外来者が、亜空間に長期間腐蝕され、怪物化したもの。
- **本質**：唯物の人間 → 唯心に同化される → 人間性を喪失。「人類の崩壊＝魂の喪失」と同源の、最終形態。
- **外見の気質**：かつては人間、今や歪んだ姿。人間の痕跡（装備、姿勢）が残り、いっそう悲哀と恐怖を誘う。
- **挙動**：純粋なルールベースAI（LLMを通さない）。具体的挙動は数値で詳細化。

### 第二分類：幻覚の実体化怪（公共型のみ作成）
- **設定上の由来**：NPCの幻覚／心魔が、唯心的な亜空間の中で実体化し、現実の怪物となったもの。
- **本質**：唯心が直接生み出す造物（感情／恐怖 → 実体）。クトゥルフ的、マーフィーの法則。
- **外見の気質**：名状しがたく、形態は恐怖に由来し、人によって異なる。
- **重要な境界**：
  - **「公共型」のみ作成**（実体化後、拠点全体を脅かす）。
  - 「私的な心魔」は別途作らない——それは既存の **NPC崩壊（isBroken）** のコードであり、流用すればよく、重複して作らない。

> この二分類のみで、派生する具体的な種類は十分に豊富である。
