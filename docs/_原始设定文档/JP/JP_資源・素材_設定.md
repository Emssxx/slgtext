# 亜空間サバイバルSLG — 資源・素材 設定書

> 本書は「資源はどこから来るのか」という世界観の核心的問いを定義する。
> **これは設定レベルの定義であり、世界観の整合性を保つためのものである。MVP段階では対応する採集／生産システムは作らない**——MVPでは資源は抽象的な数値（既存の倉庫システムで管理）とする。

---

## 一、核心的問い：亜空間に伝統的な資源は存在しない

伝統的SLGの資源論理（伐採、採掘、取水）は本作では**成立しない**：
亜空間は歪んだ異界であり、正常な自然資源は存在せず、あらゆる物質が「異常で、信用できない」ものである。

これは欠陥ではなく、本作の**特色**である：資源体系を独自のものにせざるを得ず、かつ資源を本質的に**希少**にする——これがまさにコア体験「圧迫の中で資源の決断をする」に資する。

---

## 二、資源の三つの源（統一設定）

> 一言の設定：
> **亜空間に伝統的資源はない。生存者の唯一の物質源は「AI端末」である——それは亜空間の歪んだ物質を基礎素材へと再構築する。そして真に希少な資源（食料、現実の造物）は、端末が現実世界から短時間・限定的に転送して入手する。**

### 源1：端末が亜空間物質を再構築 →【基礎素材】
- 設定：端末（ナノマシンで構成される）は、亜空間の歪んだ物質を、利用可能な基礎素材（仮に「物質」または「ナノ物質」と呼ぶ）へ再構築できる。
- 性質：その場で入手できるが、エネルギー／時間を消費する。基礎建築に用いる。
- プレイヤーの構想に対応：**ナノマシン**。

### 源2：現実世界から転送 →【希少資源】
- 設定：端末は短時間のゲートを開き、現実世界から圧縮された物資（食料、現実の造物）を転送し、亜空間で展開する。
- 性質：限定的、貴重、クールタイム／代償がある。資源の圧力を生む。
- プレイヤーの構想に対応：**転送圧縮物（カプセル式／基地車式）**。

### 源3：亜空間特産 →【特殊資源】（今後の拡張）
- 設定：亜空間には独自の「資源」がある——嵐のエネルギー、造物の残骸、変異した結晶など。
- 性質：木材や鉱石ではなく、この世界に固有の異様な物質。
- 用途：発電（嵐のエネルギーを吸収）、特殊建築など。**今後の拡張とし、MVPでは作らない。**

---

## 三、なぜこの設定が優れているか

1. **世界観の整合性**：「丸腰の生存者が、素材をどこから得るのか」に答え、破綻しない。
2. **複数の構想を統一**：ナノマシン（源1）＋転送ゲート（源2）の両方を矛盾なく取り込む。
3. **資源が本質的に希少**：自然資源がなく、端末から限定的にしか得られない → 資源の圧力が設定に内在し、意図的に希少性を設計する必要がなく、コア体験に直結する。
4. **「端末がコア」を強化**：あらゆる資源が端末を経由する → 端末が拠点の生命線となり、「プレイヤーはAI、端末はプレイヤーのアンカー」というテーマに呼応する。
5. **MVPの簡素化**：採集システムがないため、資源は抽象的な数値となり、MVPが大幅に簡素化される（下記）。

---

## 四、MVPへの意義：資源＝抽象数値、採集システムは作らない

この設定を定めた後、**MVPでは伐採・採掘のような採集ゲームプレイを作る必要はない**：

- 資源はいくつかの**抽象的な数値**（例：素材、食料）とし、**既存の倉庫システム**（sharedStorage）で管理する。
- 「端末が物質を再構築」「現実から転送」といった**生産ロジックは、MVPでは作らない**——MVPでは直接**限られた初期資源を与え**、プレイヤーの任務は**消費の管理・取捨選択**とする。
- これにより、MVPは「資源の圧迫下で決断する」ことに集中でき、「採集・生産の管理」には向かわない。

**亜空間に「自然資源がない」という設定が、かえってMVPから採集システム一式を省いてくれる。**

---

## 五、今後の拡張に回す部分（MVPでは作らない）

- 端末が物質を再構築する具体的ゲームプレイ（エネルギー消費、産出速度）。
- 転送ゲートのリフレッシュ機構（食料／資源の定期転送、クールタイム、リスク）。
- 亜空間特産の採集と用途（嵐のエネルギー発電など）。
- ナノマシンを消費可能資源とする際の詳細。

これらは「電力・AI端末・ロボット」拡張書にあり、MVPでコアの面白さを検証した後に作る。

# 【拡張記録】AI端末の技術ツリー ＋ 資源の亜空間化リネーム

> 以下は今後の拡張構想。**純粋な記録であり、MVPでは作らない。** MVP段階では資源は依然として抽象数値。

## 六、AI端末を「技術ツリーの根ノード ＋ 基礎建築のアクティベーター」とする

- 設定：あらゆる資源が端末による再構築に依存する以上、端末は自然と**技術／解放の中枢**となる。
- ゲームプレイ：AI端末があって初めて、他の機能的建築が解放される。例：
  - NPCの住居
  - 食料変換機
  - 作業台
  - （今後さらに：浄化装置、防御建築、発電機…）
- 意義：
  - **論理的整合性**——資源が端末を経由し、建築も端末で解放され、端末が生命線。
  - **明快な成長の主線**——端末を造る → さらに解放 → 拠点が発展。
  - 「プレイヤーはAI、端末はアンカー」というテーマに呼応。

## 七、自然資源の「亜空間化」リネーム表

> 伝統的SLGの資源を亜空間特産にリネーム。単なる外見替えではなく、各々に入手ロジック（ゲームプレイのフックを内包）を持たせる。
> （MVPではリネームするか否かは状況次第。リネーム自体はMVPのゲームプレイに影響しない。）

| 伝統的資源 | 本作の名称 | 入手方法 |
|---|---|---|
| 食料／パン | 生物タンパク栄養物 | 亜空間生物を撃破 → 変換して入手 |
| 水 | 亜空間生物抽出液 / 変換水源 | 生物撃破で入手 / 汚染水源を浄化変換 |
| 鉱物 | 亜空間鉱石 | 亜空間内で採集 |
| 木材 | （廃止） | 亜空間に樹木はなく、存在せず、必要もない |

### このリネームの価値
1. **世界観の独自性を強化**：資源名を見ただけで「普通の生存ゲームではない」と分かる。
2. **ゲームプレイのフックを内包**：
   - 「生物撃破で食料／水を得る」→ **戦闘**と**資源**を結びつける。
   - 「汚染水の浄化変換」→ **汚染メカニクス**に呼応。

### ⚠️ 検討を要する連鎖的帰結（未来の自分への注意）
- 「食料／水を亜空間生物の撃破で得る」は、**資源の入手が戦闘に依存する**ことを意味する。
- 帰結：主要資源がすべて戦闘頼みだと、「戦闘」が「時折の脅威」から「日常の必需」へ変わり、ゲームがアクション／戦闘寄りになる。
- これはコア「精神／資源の生存決断」「AI叙事の核を守る」と緊張を生みうる。
- **バランスの方向**（未来に作る際に再検討）：
  - 「戦闘での資源入手」の頻度を抑え、「ひたすら狩って食料稼ぎ」にならないようにする。
  - あるいは、生物撃破を「資源源の一つ」とし唯一にはしない（端末の再構築、転送など他の源も残す）。
  - 核心は：戦闘が生存の圧力に資するのであって、「精神／資源の決断」という核に取って代わらないこと。

# 【拡張記録】二次産業（加工業）＋ 完全な経済連鎖

> 純粋な記録、MVPでは作らない。これは「成熟しているが膨大」な生産連鎖システムであり、作るなら一括で設計する必要がある。

## 八、二次産業：加工

| 原料（一次） | 加工産物（二次） | 用途 |
|---|---|---|
| 亜空間鉱石 | 亜空間装甲 | 防御建築（防壁など）を解放；主な機能：亜空間嵐を防ぐ ＋ 物理的に怪物を防ぐ |
| 亜空間装甲 ＋ AI端末のアップグレード | ナノマシン | 端末のレベルが上限を制御（下記参照） |

## 九、ナノマシン と 端末レベル（重要な制約設計）

- 設定：ナノマシンは「亜空間装甲 ＋ AI端末のアップグレード」で産出される。
- **核心的制約：端末レベルがナノマシンの上限を決める。**
  - レベル1 AI端末 → ナノマシン100ユニットまで制御（上限）
  - レベル2 → 200ユニット
  - …以下同様
- 効果：**プレイヤーに端末のアップグレードを強制する**——アップグレードしなければ、より多くのマシンを制御できない。
- アップグレード条件：伝統的SLGと変わらない（資源を消費してアップグレード）、基盤メカニクスは成熟した設計を借用すればよい。

## 十、完全な経済連鎖（全体像）

```
【一次・原料】              【二次・加工】              【用途・解放】
亜空間鉱石      ──変換──→   亜空間装甲     ──解放──→   防御建築（防壁など）
                                                     用途：嵐を防ぐ ＋ 怪物に対抗
                               │
                               ├─＋端末アップグレード ─→ ナノマシン
                                                   （端末レベルが上限を制御：
                                                    Lv1→100, Lv2→200…）
生物タンパク栄養物（食料）←亜空間生物を撃破して変換
亜空間生物抽出液（水）   ←生物撃破 / 汚染水を浄化変換
```

### 設計のハイライト
1. **端末レベル＝ナノマシン上限**：アップグレードの駆動力。「端末は技術の中枢」に呼応。
2. **亜空間装甲は一物二用**：嵐を防ぐ（環境）＋怪物を防ぐ（物理）。経済連鎖に冗長がない。
3. **外殻は独自、内核は成熟**：名称／世界観は独自だが、アップグレードなどの基盤メカニクスは成熟したSLGを借用。堅実かつ実務的で、すべての歯車を原創しようと無理をしない。

### ⚠️ 複雑度の警告（未来の自分への注意）
- この経済連鎖（採集→加工→解放→アップグレード）は**完全な生産連鎖システム**であり、作業量が膨大。
- 作るなら必ず**一括で設計**し、断片的に継ぎ接ぎしない（断片的だと各段が噛み合わなくなる）。
- 必ずMVPでコアの面白さを検証した後に、「この生産連鎖が本当に必要か、どこまで深く作るか」を評価する。
- リスク：生産連鎖を作り込みすぎると、「精神／資源の生存決断 ＋ AI叙事」という核を薄めかねない。
