# 04 地图・建造・资源・环境

## 地图（2026-11-13 改版，现行方案）
- 不再用地图种子。营地是一个**固定基地**：预制的 Lv1 遗弃基地（尺寸未定）。幸存者从基地里拿到了防护服和武器。防御设施（炮台、墙）以后再做。
- 营地外是**永不消散的雾**，光也照不开。NPC 进入雾里会掉 SAN。
- 「随机传送」是假的：由 AI 导演在紧贴营地的雾里生成地形区域（废弃营地、怪物巢穴、其他人类营地、ABA 临时指挥部），区域生成后那里的雾会散开。区域之后会再消失。具体生成规则以后再讨论。
- 资源只能从区域里获得。正在考虑要不要放弃传统的资源系统。营地扩张还在考虑中。
- 实现第 1 步：永久雾，只有营地可见，进雾掉 SAN；旧的地形生成用开关关闭，代码不删。
- 营地大门：升降杆式自动门（向上抬起）。需要门柱、一个简易自动识别器（红灯 = 关、绿灯 = 开）、连杆升降装置，并用电线连起来，素材从发电机和终端机的电线、电路板里拼。门口地面**不要**黄色警示条。

### 旧版地形（保留代码，暂时停用）
土地（移速 −10%）、营地地砖（3 种）、沼泽（移速 −80%）、水面（不可行走，可以取水、捕鱼）；草、树、石头、矿石（1 / 4 / 9 格三种规格）。1 个旧单元格拆成 9 个小格，这样能做出更多不同体积和形状的建筑。

## 网格・坐标
- 坐标用纯编号（G7、J10）。语义名称先给默认值，玩家可以重命名，名字重复就加 01。
- 左下角有一个四角框浮窗常驻显示，随鼠标移动实时显示坐标和地形。
- 摄像机可以缩放。

## 建造
- 建造物数据：每种一个 ScriptableObject（`BuildableData`），先预留 width/height 字段。
- 分类：防御 / 生产 / 电力 / 基础 / 生活。造好 AI 终端机后，解锁下一阶段的一产建筑。
- 建造模式（11-07 改版）→ **建造计划（蓝图）模式**：做成老式电脑系统风格，地图上的物体都换成几何图形（树 = 三角形，石头 = 方形）。鼠标悬停时显示带微弱呼吸光的四角框；点击或拖动放置（拖动时只框住整体范围的四个角）。工具栏：撤回 / 删除 / 保存蓝图 / **测试**（实时模拟 NPC 寻路，路不通就在命令行里报告坐标）。完成后称为「蓝图完成」。游戏时间不暂停。
- 可通过和不可通过的建筑要分开（墙要有碰撞，箱子无所谓）。

## AI 终端机
- 第一个功能建筑。代码要方便修改（之后一定会改）。
- 激活前只能看到营地，激活后 NPC 可以去探索、揭开迷雾（三态迷雾：未探索 / 探索过 / 视野内）。
- 功能：物品建造台、科技树、最高升级到 3 级（框架已有，具体内容后续补充）。等级越高，可控制的纳米机器人越多（例如 1 级 100、2 级 200）。
- 界面：第一次启动时滚动显示老电脑开机代码 → 命令行风格；首页显示等级、发电量、储电量，分级菜单有「科技」「登录成员（NPC）」等。
- 结构设想：服务器机箱部分（电源、散热管、显卡）+ 制造部分（纳米机器人储存罐、类似 3D 打印机的平台和喷口）。终端机自带一台小型风力发电机（+0.1）。

## 资源（设定，MVP 中视情况使用）
- 一产：蛋白质营养物（击杀亚空间生物获得）、亚空间生物提取液 / 转换水源、亚空间矿石（没有木材）。※ 旧地形里有树和木材，跟这条设定冲突，以后要统一。
- 二产：装甲（矿物转换，用来解锁防御建筑）、纳米机器人（装甲转换 + 终端机升级）。
- 三产：AI 机器人。
- HUD：电力、水和基础材料用图标显示，配圆形格子刻度（刻度大小统一），不显示数字；资源充足时显示淡蓝色，不足时变淡黄色并不规则闪烁。点击会打开所有资源的详细数据框（小标题用英语，例如 Water）。

## 电力
- 参考潜渊症：高负荷时受损、电压不足导致短暂断电。
- 发电机设定：吸收亚空间风暴的能量转换成电能。
- 风力发电机：微风 +0.1 / 中风 +3 / 大风 +6 / 亚空间风暴 +10。电线（连线功能）把发电机接到各个设备上。连线模式下点击建筑不要打开建筑界面。

## 天气・气温（不做昼夜交替，因为跟亚空间设定不符）
- 雨：小 / 中 / 暴（重要的取水途径）。风：微 / 中 / 大。大风 + 暴雨 = 亚空间风暴。雪：分级同上，会让气温下降，也能取水。冰雹：外出会受伤。
- 气温：−10〜30 正常；30 以上每高 1 度，体力消耗增加；−10 以下行动变慢，没有防具时每低 5 度生命 −3；超过 40 或低于 −40 会限制营地设施（具体还在考虑）。加温器和降温器由终端机控制，会耗电。
- 天气浮窗：左边是雨、风、冰雹的图标（没有时对应图标不亮），右边是气温（正常绿 / 寒冷蓝 / 炎热红）。图标规格见 `06_UI与美术规范.md`。
