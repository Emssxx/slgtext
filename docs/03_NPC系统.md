# 03 NPC 系统

## 生成
- 所有 NPC 都由词条池随机生成（以前手捏的人物卡「老五/李四」已经废弃）。
- 维度：性别 + 主性格 / 社交性 / 职业（独立字段）/ 癖好、创伤。每个词条带两样东西：给 LLM 的描述，以及（可选的）对规则数值的影响（例如勇敢会降低逃跑阈值）。
- 幸存者最多 10 人，由 AI 导演生成。数据配置用 JSON / ScriptableObject。

## 行为（纯规则，不走 LLM）
- 状态机优先级：崩解 → 生命危急 → 饥饿 → 体力 → 物资 → 待命、闲逛。
- 闲置行为框架（`NpcIdleBrain` 等）：原地发呆、在营地里随机走动、随机找另一个 NPC 交谈。这个框架要写得方便以后扩展。
- **行动必须是 NPC 自发的**：不是「闲着没事才动」，而是看周围环境做判断。
  - **安全感**：跟勇敢词条挂钩。营地空旷时安全感低，墙壁和封闭区域会提高安全感 → 安全感不足的 NPC 会自己决定去建造。
  - 营地有一个玩家看不见的范围（`CampZone`）。「封闭空间」的判定和建造执行交给本地代码，AI 只负责「思考」。
- **分工优先级**（11-06）：
  - 建筑组：建筑 > 搬运 > 采集 > 医疗 > 探寻
  - 采集组：采集 > 探寻 > 搬运 > 建筑 > 医疗
  - 探寻组：探寻 > 采集 > 搬运 > 建筑 > 医疗（其他组以此类推）
- NPC 任务栏：显示分组和各自正在做的任务。

## 健康数值（2026-10-27 规格，之后有调整）
- **饥饿**：改为 100 = 饱、0 = 饿。每秒 −0.3；到 0 后生命每秒 −0.5。饥饿值低时出现「饥饿」词条（对其他 NPC 好感 −20%）。
- **体力**：最初是移动每单位 −1（之后改成 −0.3），**11-06 改成移动不消耗体力**，建造的消耗也降低了。战斗每秒 −2。休息时消耗饥饿值来恢复体力，每秒 +0.3。体力低时出现「疲惫」词条（移速 −30%，工作速度 −50%）。
- **水分**：「口渴」（体力消耗每秒 +0.3）、「口渴难耐」（每秒 +0.6）。饥饿和水分都低时出现「饥渴难耐」（好感 −20%，体力每秒 +0.6，SAN 每秒 −0.5）。每个人默认带一个水瓶。
- **生命状态词条**：健康 / 生病（移速 −40%，饥饿每秒 +0.5，SAN 每秒 −0.2）/ 受伤（移速 −60%，体力每秒 +0.5，无法工作）/ 精神病（对营地成员信任降为 0，移速 +30%，SAN 每秒 −0.2）/ 致命伤（移速 −80%，无法工作和战斗）/ 濒死（无法移动、工作和战斗）。
- 气温造成的影响见 `04_地图_建造_资源_环境.md`。

## SAN（精神）
- 勇气越高，SAN 掉得越慢（但不要太明显）。
- 低于 60：失神，说话还算正常。低于 30：出现幻觉（「我看见了魔鬼」）。
- 等于 0：不可逆，人格崩解（isBroken），脱离 LLM，开始掉血并异变（例如头上长出羊角、手上长出眼睛）。外向的人会大叫，内向的人会失语或哼唱，并陷入以前职业的幻觉（老师会开始讲课）。
- 幻觉的表现要暧昧，让玩家自己判断这个人是不是出现了幻觉。
- 饥饿、外伤都能真正致死。全员死亡就 Game Over。死亡时先做淡出（MVP 阶段）。现在有尸体爆炸和肢解效果。

## 信任与关系
- 对玩家的信任度决定听从概率（曲线已实现）。完全按信任度来，没有「为保命而违抗」的例外。只有听或不听，不做过多反应。
- NPC 之间：信任 + 友善度，单向关系（`RelationshipManager`）。
- 「说话会改变信任度」：**还没实现**，用户说之前的逻辑不自洽，需要重新构思。
- AI 机器人越多，NPC 对玩家的信任越低（设定阶段）。

## 社交系统（计划，未定稿）
NPC 之间会产生仇恨、友善、怀疑；会独立思考现在该做什么（例如田中想在某坐标建防御墙：有材料就去仓库拿，没有就去收集）；会组织集体行动，选领导者、分组（建造组、医疗组等）、互相指挥。
用户认为：这正是 AI 在这个游戏里不可替代的理由。

## NPC 蓝图提案（11-07）
NPC 想建造某个区域时，左下角弹出提示（头像 + 感叹号）→ 在专属对话框里发送建造计划 → 玩家可以批准、拒绝（NPC 可以问理由）或自己修改。
